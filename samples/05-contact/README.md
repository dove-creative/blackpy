# 닿았을 때·닿는 중·떨어졌을 때

방향키로 고양이를 움직여 제자리에 있는 별과 접촉하는 예제이다. 별의 말풍선과 웹 로그로 접촉 상태의 변화를 확인한다.

## 실행

1. 저장소 루트에서 `./scripts/Publish.ps1`을 실행하여 공통 실행부를 준비한다.
2. 이 폴더의 `시작.exe`를 더블클릭한다. 저장소 루트에서 `./samples/05-contact/시작.exe`으로 실행해도 된다.
3. 열린 웹에서 **시작**을 누른 다음 무대를 클릭해 키보드 입력 초점을 옮긴다.
4. 오른쪽 방향키를 눌러 고양이가 별에 닿을 때까지 움직인다. 약 2~3초 뒤 닿으면 키를 놓고 잠시 기다린다.
5. 왼쪽 방향키를 눌러 고양이를 별에서 떨어뜨린다.

Python 파일은 VS Code에서 편집하고 저장한 뒤 웹의 **다시 시작**으로 반영한다. VS Code의 일반 Python 실행 버튼은 사용하지 않는다.

## 확인할 동작

- 처음에는 고양이가 왼쪽, 별이 오른쪽에 있다. 별은 움직이지 않는다.
- 새로 닿으면 웹 로그에 `닿았을 때: ['고양이']`가 한 번 나온다.
- 닿아 있는 동안 별의 말풍선은 `고양이와 닿는 중이에요!`이다. 유지 이벤트는 매 프레임 실행하지만 `print()`를 넣지 않아 로그가 계속 늘어나지 않는다.
- 떨어지면 별의 말풍선이 `고양이와 떨어졌어요!`로 바뀌며, 웹 로그에 `떨어졌을 때: ['고양이']`가 한 번 나온다.
- 다시 닿았다 떨어지면 같은 전환을 반복한다. **다시 시작**은 두 캐릭터를 초기 위치로 돌린다.

접촉은 그림의 회전과 무관한 사각 범위로 확인한다. 말풍선과 이름표는 접촉 범위에 포함하지 않는다. `print()` 결과는 웹 아래의 로그에서 확인한다.

## 바꿔 보기

고양이 파일의 `앞으로(120)` 값을 모두 60으로 바꾸면 절반 속도로 움직인다. 유지 이벤트의 숫자는 한 번의 이동 거리가 아닌 초당 이동량이다. 별 파일의 말하기 문구를 바꾸어 접촉 상태마다 다른 이야기를 만들 수 있다.

## 출력

결과는 웹 무대·로그에 표시하며 별도 파일을 만들지 않는다. 웹의 중지 버튼으로 끝낸다.
