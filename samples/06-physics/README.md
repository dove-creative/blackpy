# 공의 중력·충격·정지

공이 고정 발판에 떨어지고 한 번의 충격으로 움직이는 예제이다. '충돌만' 발판과 '물리' 공의 차이, 중력과 정지, 무대 사방의 경계 충돌을 확인한다.

## 실행

1. 사용할 Python에 `python -m pip install --upgrade blackpy`로 BlackPy 0.1.1 이상을 설치한다. 자세한 설치 조건은 [사용 안내](../../docs/Usage.md)에 있다.
2. 이 폴더의 `시작.pyw`를 더블클릭한다. 저장소 루트에서 `python -m blackpy run ./samples/06-physics`로 실행해도 된다.
3. 웹의 **시작**을 누르고 무대를 클릭하여 키보드 입력 초점을 옮긴다.
4. 공이 발판 위에 내려앉은 뒤 스페이스를 눌러 위로 한 번 민다.
5. 왼쪽·오른쪽 방향키로 옆으로 밀고 무대 경계에 막히는지 확인한다.
6. 움직이는 공을 클릭하여 현재 속도를 지운다. 엔터는 속도를 지우고 공을 처음 위치로 돌린다.

VS Code에서 이 폴더를 열고 BlackPy를 설치한 Python을 선택하면 `공.py`의 'Run Python File'로도 같은 무대를 열 수 있다. 학생 파일에 import를 추가하지 않으며 별도 Python 물리 패키지를 설치하지 않는다. `Debug.bat`은 같은 실행기를 콘솔 모드로 실행한다.

## 확인할 동작

- 공은 처음 `(0, 80)`에서 아래로 떨어진다. 발판은 `(0, -180)`에서 움직이지 않는다.
- 공은 발판 위에 내려앉고 `공이 닿은 객체: ['발판']`을 콘솔에 한 번 출력한다. 정지한 중심 위치는 대략 `(0, -138)`이다.
- 스페이스를 한 번 누르면 공이 위로 올라간 뒤 중력으로 다시 내려온다. 키를 계속 누르고 있어도 최초 누름에만 충격을 준다.
- 방향키로 옆으로 밀면 공은 발판에서 벗어나 무대 바닥으로 떨어진다. 왼쪽·오른쪽·위·아래의 경계 벽 때문에 무대 밖으로 나가지 않는다.
- 무대의 보이지 않는 경계 벽은 닿은 객체 이름 목록에 나오지 않는다.
- 공을 클릭하면 그 순간의 속도만 0이 된다. 공중이라면 중력이 계속 작용하여 다시 아래로 움직인다.
- 엔터를 누르면 공이 처음 위치로 돌아와 다시 떨어진다. 웹의 **다시 시작**은 모든 객체를 초기 상태로 되돌린다.

공은 물리 충돌로 자동 회전하지 않는다. 충돌 범위는 그림의 회전과 무관한 사각형이다. `정지()`는 웹의 중지 버튼과 달리 실행 전체를 끝내지 않는다.

## 바꿔 보기

공 파일의 `무게_설정(1)`을 `무게_설정(2)`로 바꾸면 같은 충격에서 속도 변화가 절반이 된다. 중력에 의한 낙하 가속도는 같다. `힘_작용(90, 6)`의 6을 바꾸면 한 번 밀 때의 충격량을 비교할 수 있다.

`키_클릭`을 `키_클릭_중`으로 바꾸면 누르는 매 프레임 충격을 반복해서 더하므로 아주 빠르게 움직일 수 있다. 한 번의 충격과 계속 반복하는 충격을 구분하여 실험한다.

## 출력

결과는 웹 무대와 콘솔에 표시하며 별도 파일을 만들지 않는다. 웹의 중지 버튼으로 끝내고 마지막 브라우저 탭을 닫으면 실행부도 종료된다.
