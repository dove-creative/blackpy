# 디스플레이 점수판

BlackPy 0.1.15 이상에서 실행하는 전역변수 예제이다.

1. 무대를 열고 시작하기 전에 점수판을 누른다.
2. 무대 아래 콘솔 입력칸에 `동전_수`를 입력하고 Enter를 누른다.
3. 시작을 누르고 두 동전을 번갈아 누른다. 점수판의 값이 함께 올라간다.
4. 다시 시작하면 동전 수는 0부터 시작하고 변수 연결은 유지된다.

점수판에는 Python 파일이나 반복문이 필요하지 않다. 배경의 함수 밖에서 만든 `동전_수`를 두 동전이 `global`로 바꾸면 연결된 디스플레이가 표시한다. 중지 후 점수판을 다시 누르면 다른 변수로 연결할 수 있다. 이름을 비우면 연결이 해제된다. 없는 변수는 `—`로 표시한다.

실행은 이 폴더의 `시작.pyw` 또는 저장소 루트의 다음 명령을 사용한다.

```powershell
python -m blackpy run ./samples/07-display
```
