# 순서대로 움직이기

시작 이벤트의 이동·회전·반복과 명령 실행 순서를 확인하는 예제이다.

## 실행

`python -m pip install blackpy`로 설치한 뒤 이 폴더의 `시작.pyw`를 더블클릭한다. 명령줄에서는 저장소 루트에서 `python -m blackpy run ./samples/01-movement`로 연다. 웹의 시작 버튼을 누른다. 설치 환경과 오류 확인 방법은 [샘플 실행 안내](../README.md)에 있다.

0.1.1 설치형에서는 이 폴더의 `고양이.py`나 `배경.py`에서 VS Code의 'Run Python File'을 눌러도 된다. 같은 폴더의 어느 `.py`에서 열어도 이 예제 전체를 실행한다. 설치와 직접 실행 조건은 [샘플 실행 안내](../README.md)에 있다.

## 확인할 동작

고양이는 오른쪽·위·왼쪽·아래로 각각 160만큼 걷고, 매번 왼쪽으로 90도 돈다. 약 5초 뒤 처음 위치인 `(-160, -80)`과 방향 0으로 돌아오며 실행이 완료된다. 말풍선과 콘솔에 완료 메시지가 나온다.

`고양이.py`의 `속도 = 1`을 `속도 = 2`로 바꾸고 저장한 뒤 다시 시작하면 같은 거리를 더 빨리 이동한다. `앞으로(160)`의 숫자는 총 이동 거리이다.

## 출력

결과는 웹 무대·콘솔에 표시하며 별도 파일을 만들지 않는다.
