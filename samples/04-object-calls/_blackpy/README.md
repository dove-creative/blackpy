# 객체의 함수를 차례로 호출하기

배경에서 이름으로 고양이와 자동차를 찾아 각 파일의 함수를 호출하는 예제이다. 인자로 이동 거리를 전달하며 함수가 끝나면 반환값을 받는다.

## 실행

BlackPy 0.1.17 이상을 설치하고 이 폴더의 `시작.pyw`를 실행한다. 저장소 루트에서는 `python -m blackpy run ./samples/04-object-calls`로 연다.

## 조작과 예상 결과

- 빈 곳을 클릭하거나 스페이스를 누르면 고양이가 먼저 60만큼 갔다가 돌아온다.
- 고양이의 함수가 끝난 뒤 자동차가 60만큼 갔다가 돌아온다.
- 콘솔에는 고양이 출발·완료, 자동차 출발·완료가 차례로 표시된다.
- 두 객체가 돌아오면 배경에 '모두 돌아왔어요!'가 표시된다. 다시 눌러 반복할 수 있다.
- 서로 다른 이벤트는 함께 실행될 수 있으므로, 관찰할 때는 한 동작이 끝난 뒤 다시 누른다.

## 바꾸어 보기

배경의 함수 호출 순서를 바꾸거나 `출발하기(60)`의 인자를 바꾸어 순서와 거리를 비교한다. 함수 이름은 해당 캐릭터 파일의 정의와 같아야 한다. 수정 후 다시 시작한다.
