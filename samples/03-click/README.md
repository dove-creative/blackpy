# 공을 누르고 놓기

자신 클릭의 시작·유지·종료, 크기 변경과 배경 클릭을 확인하는 예제이다.

## 실행

저장소 루트에서 `./scripts/Publish.ps1`을 한 번 실행한 뒤 이 폴더의 `시작.exe`를 더블클릭한다. 명령줄에서는 루트에서 `./samples/03-click/시작.exe`으로 연다. 웹의 시작 버튼을 누른다.

## 확인할 동작

| 조작 | 예상 결과 |
| --- | --- |
| 공에 마우스 왼쪽 버튼 누르기 | 공이 1.5배 커지고 누름 메시지가 나온다. |
| 누른 채 기다리기 | 공이 초당 180도 회전한다. |
| 버튼 놓기 | 회전이 멈추고 원래 크기로 돌아온다. |
| 공에서 누른 채 빈 곳으로 옮겨 놓기 | 공의 놓기 이벤트가 실행된다. |
| 빈 곳을 새로 클릭하기 | 배경 메시지와 로그에 배경 클릭이 표시된다. |

공을 클릭했을 때는 배경 클릭이 발생하지 않는다. 누르기 시작한 대상은 버튼을 놓을 때까지 유지된다.

## 출력

결과는 웹 무대·로그에 표시하며 별도 파일을 만들지 않는다. 웹의 중지 버튼으로 끝낸다.
