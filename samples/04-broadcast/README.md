# 방송으로 함께 움직이기

한 번의 방송을 배경과 두 캐릭터가 함께 받는 예제이다. 방송을 보낸 배경도 수신 대상이다.

## 실행

1. 저장소 루트에서 `./scripts/Publish.ps1`을 실행하여 공통 실행부를 준비한다.
2. 이 폴더의 `시작.exe`를 더블클릭한다. 저장소 루트에서 `./samples/04-broadcast/시작.exe`으로 실행해도 된다.
3. 열린 웹에서 **시작**을 누른다.
4. 캐릭터가 없는 무대의 빈 곳을 클릭한다. 이후에는 무대에 초점이 있는 상태에서 스페이스를 눌러도 된다.

Python 파일은 VS Code에서 편집하고 저장한 뒤 웹의 **다시 시작**으로 반영한다. VS Code의 일반 Python 실행 버튼은 사용하지 않는다.

## 확인할 동작

- 빈 곳 클릭 또는 스페이스 입력은 배경에서 `출발` 신호를 방송한다. 캐릭터 위의 클릭은 배경 클릭으로 처리하지 않는다.
- 고양이와 자동차는 서로 다른 말을 하며 동시에 가운데를 향해 60만큼 움직인다. 잠깐 기다린 뒤 각각 처음 위치로 돌아온다.
- 배경 안내에는 자신이 보낸 신호를 배경도 받았다는 문구가 표시된다.
- `print()` 결과는 웹 아래의 로그에서 확인한다. 한 번의 방송에 배경·고양이·자동차의 메시지가 하나씩 나온다.
- 두 캐릭터가 돌아온 다음 다시 방송하면 같은 동작을 반복한다. 수신 동작이 진행 중일 때 같은 신호가 다시 와도 해당 캐릭터의 동작은 중복해서 시작하지 않는다.

## 바꿔 보기

고양이 파일의 `앞으로(60)`과 `앞으로(-60)`을 각각 100과 -100으로 바꾸면 고양이만 더 멀리 갔다가 돌아온다. 방송 이름을 바꿀 때는 보내는 곳과 받는 곳의 `"출발"`을 함께 바꾼다.

## 출력

결과는 웹 무대·로그에 표시하며 별도 파일을 만들지 않는다. 웹의 중지 버튼으로 끝낸다.
