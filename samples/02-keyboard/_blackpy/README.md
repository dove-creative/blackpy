# 방향키로 움직이기

키를 누르는 순간·누르는 동안·떼는 순간과 유지 이벤트의 초당 이동을 확인하는 예제이다.

## 실행

`python -m pip install blackpy`로 설치한 뒤 이 폴더의 `시작.pyw`를 더블클릭한다. 명령줄에서는 저장소 루트에서 `python -m blackpy run ./samples/02-keyboard`로 연다. 웹의 시작 버튼을 누르고 무대를 클릭해 초점을 옮긴다. 설치 환경과 오류 확인 방법은 [샘플 실행 안내](../../README.md)에 있다.

0.1.1 설치형에서는 이 폴더의 `고양이.py`나 `배경.py`에서 VS Code의 'Run Python File'을 눌러도 된다. 같은 폴더의 어느 `.py`에서 열어도 이 예제 전체를 실행한다. 설치와 직접 실행 조건은 [샘플 실행 안내](../../README.md)에 있다.

## 확인할 동작

| 조작 | 예상 결과 |
| --- | --- |
| 방향키 누르기 | 말풍선과 콘솔에 누른 키가 한 번 표시된다. |
| 방향키 누르고 있기 | 해당 방향으로 초당 120만큼 이동한다. |
| 방향키 떼기 | 이동이 멈추고 말풍선과 콘솔에 뗀 키가 표시된다. |
| 방향키를 놓은 뒤 스페이스 누르기 | 중앙 `(0, 0)`으로 즉시 돌아온다. |

`키_클릭_중`의 `앞으로(120)`에서 숫자는 초당 이동량이다. `01-movement`의 총 이동 거리와 비교할 수 있다. 화면 밖으로 이동했다면 방향키를 놓고 스페이스를 누른다.

## 출력

결과는 웹 무대·콘솔에 표시하며 별도 파일을 만들지 않는다. 입력을 기다리는 예제이므로 웹의 중지 버튼으로 끝낸다.
