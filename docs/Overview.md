# BlackPy 개요

BlackPy는 저장한 Python 명령을 캐릭터의 움직임으로 보여 주는 로컬 교육용 실행 환경이다.

## 목차

- 소개
- 학습 흐름
- 구성과 관계
- 제공 범위
- 배포와 수업 자료

## 소개

| 항목 | 내용 |
| --- | --- |
| 개요 | 학생의 Python 파일을 실행하고 움직임과 출력을 웹 무대에 표시하는 프로그램이다. |
| 목적 | 어린 학생이 준비된 코드의 숫자·명령을 바꾸며 실행 순서와 결과를 비교하게 하는 것이다. |
| 구현 | Python 명령, 로컬 실행부, 웹 무대를 연결하고 저장·실행·관찰의 흐름을 제공한다. |

Python 파일은 학생의 편집기에 남고, 웹은 실행과 결과 확인을 담당한다. 학생에게 서버 설정이나 내부 통신 구현을 요구하지 않는다.

## 학습 흐름

학생은 예제 폴더의 코드를 편집기에 열고 한 곳을 바꾼 뒤 저장한다. 웹에서 실행하면 캐릭터가 명령 순서대로 움직이고, 결과와 출력이 남는다. 학생은 예상과 실제 결과를 비교한 뒤 코드를 다시 바꾼다.

각 이동 명령은 동작이 끝난 뒤 반환한다. 다음 줄이 실행되는 시점을 움직임과 연결해 관찰할 수 있다. 준비된 경주와 드리블 명령은 여러 캐릭터가 함께 움직이는 활동을 제공한다.

## 구성과 관계

| 구성 | 책임 |
| --- | --- |
| 학생 Python 파일 | 실행할 명령의 순서와 값을 표현한다. |
| Python 지원 모듈 | 학생 명령을 이동 요청이나 장면으로 표현한다. |
| 로컬 실행부 | Python 실행, 명령 검증, 상태 전달, 중지와 정리를 담당한다. |
| 웹 무대 | 현재 장면과 출력·오류를 표시하고 실행 제어를 제공한다. |

기본 고양이 이동은 UniEngine의 이동 기능을 사용한다. 다섯 놀이의 장면은 Python에서 계산한 캐릭터 상태를 실행부가 검증하고 웹으로 전달한다. 두 흐름은 실행 시작·중지와 출력 관리의 같은 경계를 사용한다.

## 제공 범위

기본 고양이 예제와 자동차 이동·댄스 파티·달리기 경주·농구공 드리블·으스스한 숲의 다섯 예제를 제공한다. 캐릭터의 이동·회전·속도, 준비된 배경과 외형, 경주·드리블 동작을 사용할 수 있다.

무대의 논리 크기는 800×600이다. 중앙이 원점이며 오른쪽과 위쪽이 양수이다. 실행을 마치거나 중지한 뒤 마지막 장면은 남고, 새 실행을 시작하면 초기화된다.

키보드·클릭 조작, 접촉 판정, 아이템·점수·소리는 현재 범위에 포함하지 않는다. `input()`을 통한 표준입력도 제공하지 않는다. 브라우저 저장소에는 실행 기록을 저장하지 않는다.

## 배포와 수업 자료

배포 폴더는 기본 예제와 공통 실행부를 담은 `실습` 폴더, 다섯 놀이 폴더로 구성한다. 놀이 폴더들은 공통 실행부를 공유하므로 배포 폴더 전체를 함께 전달한다. 갱신할 때 기존 학생의 `main.py`는 보존한다.

BlackPy 저장소는 실행 프로그램·지원 모듈·예제의 원본을 관리한다. 구체적인 실행 방법은 [Usage](Usage.md), 실행 구조와 제약은 [Implementation](Implementation.md)에 있다.
