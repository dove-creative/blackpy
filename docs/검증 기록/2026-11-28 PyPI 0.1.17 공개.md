# PyPI 0.1.17 공개 검증 기록

## 공개 결과

BlackPy 0.1.17을 2026-11-28 10:09 KST에 PyPI에 공개하였다. 객체별 함수 호출, 무대 전역변수, 디스플레이와 이름표 표시 설정을 포함한 커밋 `01e9ccf96af7a9908bc866a7b6a6ad77a27d780d`가 공개 기준이다.

동일 커밋에서 `expected_version=0.1.17`, `publish=false`의 [사전 검증](https://github.com/dove-creative/blackpy/actions/runs/46091040381)이 성공한 뒤 `publish=true`의 [공개 실행](https://github.com/dove-creative/blackpy/actions/runs/46091369227)을 수행하였다. 공개 실행도 전체 검증을 다시 수행했으며, `pypi` 환경의 Trusted Publishing으로 같은 실행에서 검증한 wheel을 재빌드 없이 업로드하였다.

[PyPI 공개 페이지](https://pypi.org/project/blackpy/0.1.17/)와 최신 버전 API가 0.1.17을 반환하는 것을 확인하였다. Windows x64용이며 Python 3.10 이상을 요구한다.

## 공개 파일 대조

- 파일: `blackpy-0.1.17-py3-none-win_amd64.whl`
- 크기: 49,034,632바이트
- SHA-256: `085c9de4c1305efebf95734da1d2e5b005a1fd75c1d0ec629bb5ceebb4dc13e8`
- Actions 산출물 ID: `15241431588`
- 산출물 ZIP SHA-256: `27fbca1460e9285e1458f5d2db1b73aea60acec547429f94370aaf8666a17c55`

GitHub 산출물 ZIP의 해시를 Actions 메타데이터와 비교하고, 그 안의 wheel 해시를 PyPI 메타데이터 및 네 환경의 pip 설치 보고서와 대조하였다. 모두 일치하였다. 각 환경에 설치된 패키지와 자동 실행 지원 파일 390개의 내용도 공개 wheel과 일치하였다.

이 공개본은 앞선 로컬 빌드의 wheel 해시와 구분한다. 터미널 사용자 사이트와 VS Code에서 선택한 pygame 가상환경에는 PyPI 공개본을 다시 설치하였다.

## 공개 설치와 업그레이드

Windows x64, Python 3.13.18에서 다음 경로를 확인하였다.

| 환경 | 확인 결과 |
| --- | --- |
| 검사용 가상환경 | PyPI의 0.1.12 설치 후 `python -m pip install --upgrade blackpy`로 0.1.17 설치 |
| 패키지가 없는 가상환경 | `python -m pip install blackpy`로 최신 0.1.17 설치 |
| 터미널 Python 사용자 사이트 | PyPI 0.1.17 재설치·실행 통과 |
| VS Code pygame 가상환경 | PyPI 0.1.17 재설치·실행 통과 |

업그레이드 전 만든 학생 프로젝트의 Python 파일·설정·편집기 안내 5개 파일이 바이트 단위로 보존되었다. 네 환경 모두 새 프로젝트를 만들고 설치된 실행부에서 다음 동작을 확인하였다.

- 이름으로 찾은 객체의 함수 호출, 중첩된 다른 객체 호출, 인자 전달과 반환값 10이다.
- 전역 점수가 5가 되고 디스플레이에 표시되며 대상 객체가 숨겨지고 다른 객체의 말풍선이 표시되는 동작이다.
- `showLabels=false` 설정의 프로젝트 응답과 다시 시작 후 점수 초기화이다.
- 마지막 연결 종료 후 실행기가 정상 종료하고 학생 코드가 보존되는 동작이다.

공개 직후 첫 신규 설치 요청은 이전 0.1.12를 반환하였다. 이후 PyPI 인덱스가 최신 0.1.17을 반환하는 것을 확인하고, 해당 검사용 환경의 패키지를 제거한 뒤 버전 지정 없는 신규 설치를 다시 수행하여 통과하였다. 최초 응답과 재검증 결과를 모두 `artifacts/pypi-0.1.17`에 보관하였다.

## 검증 범위

실행 검사는 실제 설치된 C#·Python 실행부와 HTTP·WebSocket 응답을 사용하였다. 별도의 브라우저 수동 조작, VS Code·Pylance 화면 검사 및 SDK가 없는 별도 장비의 실행 검사는 이번 공개 작업에 포함하지 않았다. Python 3.10의 별도 재검증은 수행하지 않았다.
