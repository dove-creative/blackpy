# 프로젝트 이미지 검증 기록

## 변경 범위

배경과 캐릭터 설정에 선택 항목 `image`를 추가하였다. 값은 `project.json`과 같은 폴더(`_blackpy`, 이전 형식은 프로젝트 바로 아래)에 둔 png·jpg·gif·webp·svg 파일 이름이다. 프로젝트 로더는 이름·확장자·존재·5MB 이하·연결 파일 여부를 검사하고, 실행부는 토큰을 요구하는 `/api/image`로 설정에 적힌 이름만 제공한다. 응답에는 확장자에 맞는 형식과 sandbox 콘텐츠 보안 정책을 붙인다. `image`가 없는 설정은 이전과 같은 JSON으로 전달한다.

웹은 프로젝트 정보를 받은 뒤 그림을 요청해 객체 URL로 디코딩한다. 렌더러는 장면의 배경 모양이 설정의 `kind`와 같을 때 배경 그림을 800×600으로, 설정 순서의 캐릭터에 캐릭터 그림을 `kind`의 상자 크기로 그린다. 크기·클릭·접촉·물리 판정은 기존 `kind`를 유지하며 Python 런타임은 바뀌지 않았다.

같은 날 수업 자료용으로 본체에 넣었던 `lake`·`spacecenter` 배경은 제거하였다. 추가 그림은 BlackPy 본체가 아닌 각 프로젝트의 `_blackpy` 폴더에서 읽는다. 버전은 0.1.6이다.

## 자동 검증

2026-11-14 KST, Windows 개발 컴퓨터에서 실행하였다. PowerShell 7.7.0을 winget으로 설치한 뒤 `scripts/Verify-Dependencies.ps1`, `dotnet test`, Python unittest 전체 탐색, `scripts/Publish.ps1`, 실행 통합·샘플·웹·폴더 배포 검사, `scripts/Build-Wheel.ps1`, 패키지·편집기·실행기·직접 실행 검사를 순서대로 수행하였다.

| 검증 | 결과 |
| --- | --- |
| 고정 NuGet 의존성 | 2개 통과 |
| C# | 143/143 통과 |
| Python | 108/108 통과 |
| 웹 | 36/36 통과 |
| 실행 통합·브라우저 수명 | 40/40 통과 |
| 샘플 | 6/6 통과 |
| 패키지·편집기·실행기·직접 실행 | 31/31 통과 |

| wheel 메타데이터 | Twine strict 통과 |

일반 자동화 테스트는 합계 364개이다. C# 검사는 `_blackpy` 폴더의 그림 읽기, 형식 판정, 설정에 없는 이름과 `project.json`의 404, 하위 경로·경로 이동·지원하지 않는 확장자·빈 이름·없는 파일의 400, 그림이 없는 설정의 JSON에 `image`가 나타나지 않는 것을 포함한다. 웹 검사는 배경 모양이 같을 때만 배경 그림을 쓰고 해당 캐릭터에만 그림을 쓰는지 확인한다. 통합 검사는 실제 실행부에서 토큰 없는 요청의 401, 설정에 없는 이름의 404, SVG 형식과 sandbox 정책, 잘못된 경로 설정의 실행 거절을 확인한다.

처음 패키지 검사에서 그림이 없는 설정에도 `image: null`이 전달되어 프로젝트 정보 일치 검사 14개가 실패하였다. 값이 없으면 직렬화하지 않도록 고친 뒤 전체 순서를 다시 실행하여 위 결과를 얻었다.

- 파일: `artifacts/wheels/blackpy-0.1.6-py3-none-win_amd64.whl`

## 로컬 설치

검증한 wheel을 0.1.5가 설치되어 있던 환경에 설치하였다.

| 환경 | 결과 |
| --- | --- |
| VS Code 기본 pygame 가상환경(Python 3.13) | 0.1.6 설치 |
| Anaconda Python 3.10 사용자 site-packages | 0.1.6 설치 |
| 터미널의 uv 관리 Python 3.13 사용자 site-packages | 0.1.6 설치 |

uv 관리 Python은 PEP 668 외부 관리 환경으로 표시되어 일반 `--user` 설치를 거절하였다. 0.1.5가 있던 같은 사용자 site-packages에 사용자 승인을 받아 `--user --break-system-packages`로 교체 설치하였으며 uv가 관리하는 Python 본체는 변경하지 않았다. 이 Python은 PATH의 첫 `python`이므로 수업 폴더의 `시작.bat`이 사용한다. 갱신 전에는 `시작.bat`이 0.1.5로 실행되어 `image`를 무시하고 기본 배경과 로켓 모양을 그렸다.

## 수업 프로젝트 실행

수업 익힘책의 교사용 08번 프로젝트를 임시 복사하여 설치형 명령 `python -m blackpy run`으로 실제 웹 무대에서 실행하였다.

- 로켓 카운트다운(pygame 가상환경): 우주센터 배경과 로켓 그림이 무대에 그려졌다. 3을 입력하면 3, 2, 1과 '발사!'를 말하고 (0, 412)까지 올라가 무대 밖으로 나갔다. 개발 배포본에서도 5 입력 시 5~1과 '발사!'를 확인하였다.
- 고양이 낚시 일기(Anaconda Python 3.10): 낚시터 그림이 배경으로 그려졌다. 5·1·3 입력 시 모두 18, 친구 몫 9.0을 출력·말하고 고양이가 (-240, -120)에서 좌우 반전된 채 끝났다. 개발 배포본에서도 3·2·4 입력 시 모두 20, 친구 몫 10.0을 확인하였다.
- `시작.bat`과 같은 PATH의 `python -m blackpy run .`(uv Python 3.13)으로 학생용 두 08번 폴더 사본을 열었을 때 우주센터·로켓 그림과 낚시터 그림이 무대에 표시되었다.
