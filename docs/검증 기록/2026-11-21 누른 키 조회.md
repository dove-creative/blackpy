# 0.1.11 누른 키 조회

## 입력 동작

키를 누르기 전에는 빈 리스트, 두 키를 누르면 정렬된 키 이름, 하나를 놓으면 남은 키 이름을 얻었다. 전체 입력을 초기화하면 빈 리스트를 얻었다. 한 번 받은 리스트를 수정해도 배경과 캐릭터의 다음 조회에 영향을 주지 않았고, 이전에 받은 리스트도 키를 놓은 뒤 원래 값을 유지하였다.

## 빌드와 설치

Windows x64에서 .NET 151개, Python 131개, 실행부 통합·샘플 50개, 웹 단위 38개, 설치·편집기·런처·직접 실행 31개 테스트가 통과하였다. 의존성 고정, 폴더 배포와 Twine 엄격 검사를 통과하였다. 검증한 wheel의 SHA-256은 `ae389ce11492a8abd030197911b47a8ae407cf44464e2d75086156926932dd6a`이다.

uv 관리 CPython 사용자 설치, VS Code pygame 가상환경, Anaconda 사용자 설치에서 각각 새 프로젝트를 생성하고 학생 파일로 웹 무대를 실행하였다. 버스는 `시작`의 반복문에서 0.1씩 전진하고, `a`를 누르는 동안에도 계속 움직였다. 스페이스바를 함께 누르자 반복이 끝나고 “문이 열립니다!”가 표시되었다. 키를 놓은 뒤에도 최종 위치는 유지되었다.
