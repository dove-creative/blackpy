# 프로퍼티 대입 안내 숨김 검증 기록

## 변경 범위

웹 명령 목록에서 위치·방향·속도·크기·가시성·배경의 직접 대입 예시 6개를 숨겼다. 대입 예시만 있던 배경 변경 카드는 제거하고, 위치·방향·속도 카드의 제목을 남은 행에 맞게 정리하였다. 상태 읽기와 함수형 변경 명령은 유지하였다.

Python의 프로퍼티 읽기·대입·증감 처리, 편집기 안내와 학생 파일은 변경하지 않았다. 사용 안내에는 웹의 표시 범위와 Python에서 계속 지원하는 대입 기능을 구분하여 기록하였다.

## 실행 환경

2026-11-12 Windows x64 개발 환경에서 Node.js 24.15.0, Python 3.13.18, PowerShell 7.6.9를 사용하였다.

## 검증 결과

| 명령 | 결과 |
| --- | --- |
| `node --test tests/Web*.test.mjs` | 20/20 통과이다. 대입 예시 숨김, 상태 읽기·함수형 명령 유지, 복사·대상 선택·입력·렌더링을 확인하였다. |
| `python -m unittest discover -s tests -p 'test_*.py'` | 57/57 통과이다. 기존 상태 대입·증감, 타입 주석이 있는 대입·분해 대입과 이벤트 실행을 포함한다. |
| 변경 파일의 `git diff --check` | 통과이다. 저장소 전체 검사에서는 기존 샘플 파일의 EOF 빈 행 경고가 남아 있으며 해당 파일은 수정하지 않았다. |

로그는 `artifacts/test-results/property-assignment-web.log`와 `artifacts/test-results/property-assignment-python.log`에 보관하였다.

## 영향과 미검증 범위

확인한 게임 자료는 이전 15개 놀이·구형 BlackPy 자료이며, 이번 명령 목록과 직접 대응하는 현재 교안은 확인되지 않았다. 대입의 실행 의미는 유지되며 외부 학생 HTML·교안은 수정하지 않았다.

이번 변경은 웹 명령 목록에 한정된다. 실제 브라우저 화면 조작, .NET 빌드, 전체 통합·배포·wheel 검사와 새 패키지 배포는 수행하지 않았다. 이미 설치한 패키지와 기존 배포본은 이번 소스 수정으로 갱신되지 않는다.
