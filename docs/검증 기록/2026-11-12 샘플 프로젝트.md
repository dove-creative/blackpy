# BlackPy 샘플 프로젝트 검증 기록

이 문서는 2026-11-12에 추가한 실행 예제 5개의 검증 결과이다.

## 변경 범위

`samples`에 순차 이동, 키 입력, 클릭, 방송, 접촉 프로젝트를 추가하였다. 각 프로젝트는 설정·배경·캐릭터 코드와 시작 BAT, 조작 방법을 설명하는 README를 가진다. 실행부는 기존 공통 배포본을 사용한다.

샘플 통합 테스트와 문서 안내를 추가하였다. 이번 샘플 작업에서는 실행부·공개 API·배포 스크립트를 변경하지 않았다.

## 환경과 결과

Windows x64, Python 3.13.18, Node.js 24.15.0, PowerShell 7.6.9에서 확인하였다. 기존 `artifacts/blackpy/실습/_runtime`을 사용했으며 Python 지원 모듈 4개의 SHA-256은 현재 원본과 일치하였다.

| 검증 | 실제 결과 |
| --- | --- |
| `node --test tests/Samples.test.mjs` | 5개 통과, 실패·건너뜀 없음. 최종 실행 약 16.8초이다. |
| 예제별 `시작.bat` | 5개 모두 올바른 캐릭터·배경 설정으로 호스트를 열었다. |
| Python·설정 | Python 12개 구문 검사와 프로젝트 설정 5개의 참조 파일 확인을 통과하였다. |
| 파일 형식 | BAT 5개는 UTF-8 무BOM·CRLF, 나머지 새 파일은 UTF-8 무BOM·LF이다. 최종 개행·줄 끝 공백 검사를 통과하였다. |
| 프로세스 정리 | 검사 종료 뒤 BlackPy 호스트와 해당 Python 실행기가 남아 있지 않았다. |

## 확인한 동작

- 이동은 네 번의 이동·회전 뒤 초기 위치·방향으로 돌아오고 실행이 완료되었다.
- 키 입력은 네 방향으로 이동하고, 떼면 멈추며 스페이스로 중앙에 돌아왔다. 시작 로그는 입력마다 한 번이었다.
- 공을 누르면 크기가 커지고 회전하였다. 누른 채 포인터를 옮겨 놓아도 공의 종료 이벤트가 실행되었으며 배경 클릭은 별도로 처리되었다.
- 방송은 송신 배경과 두 캐릭터에 전달되었다. 두 캐릭터가 함께 왕복하고, 스페이스로 다시 방송해 같은 동작을 완료하였다.
- 접촉은 시작·종료 로그에 고양이 이름을 전달하였다. 닿는 동안 별의 말풍선을 유지하고 로그를 반복 출력하지 않았다.

통합 검사는 각 프로젝트를 임시 폴더에 복사한 뒤 실제 Python·HTTP·WebSocket으로 실행하였다. BAT 검사는 한글·공백이 있는 임시 폴더에 `samples`를 복사하고, 공통 `artifacts`를 가리키는 디렉터리 연결을 두었다. 다른 작업 폴더에서 숨김 실행하고 `/api/project`의 설정을 확인한 뒤 테스트 프로세스를 종료하였다. 런처 결과는 `artifacts/test-results/sample-launchers.json`에 기록하였다.

## 검사 중 보완과 한계

초기 재검증에서 키 해제 로그를 받은 직후 이전 화면 좌표를 읽는 테스트 실패가 한 번 발생하였다. 로그와 장면은 별도로 전달되므로 해제 말풍선이 포함된 장면까지 기다리도록 검사를 보완하였다. 반복 방송도 새 동작의 시작과 완료 장면을 모두 확인한다. 방향 0도 검사는 부동소수점 누적으로 360도에 가까운 값도 허용한다.

이번 범위는 샘플 실행·런처 검증이다. C#·Python·웹 전체 단위 테스트와 전체 배포 검사는 다시 실행하지 않았다. 샘플별 실제 브라우저 화면, 별도 학생 장비와 Python 3.10 환경은 확인하지 않았다. 외부 수업 자료의 수정·재배포는 이번 작업에 포함하지 않았다.
