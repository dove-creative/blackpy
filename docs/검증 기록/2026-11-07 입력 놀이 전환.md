# BlackPy 입력 놀이 전환 기록

이 문서는 2026-11-07에 수행한 소리 기능 제거와 입력 중심 수업 전환의 변경·검증 경계 기록이다.

## 변경

- `stage.play_note`와 음 재생 전용 잠금을 제거하였다. 현재 사용 안내와 예제에서 소리 활동을 제외하였다.
- 15단원을 음악 만들기에서 자동차 주차하기로 교체하였다. 방향키를 누르는 동안 운전하고, 키를 놓은 뒤 스페이스로 주차를 확인한다.
- 1단원 방향키 운전, 2단원 고양이 클릭 춤, 4단원 공 클릭 드리블, 5단원 클릭 대상별 행동을 추가하였다.
- 6단원 방향키 술래잡기, 7단원 스페이스 골프, 8단원 키 입력마다 목록의 다음 동작, 9단원 엔터로 우주 여행을 시작하도록 바꾸었다.
- 3단원의 자동 경주를 유지하여 15개 중 14개 단원이 직접 입력을 사용하는 구성이 되었다.
- 학생 HTML·교안·시작 코드·목차·선행 요소 표를 함께 수정하였다. 학생 코드가 이전 배포 원본과 같은지 확인한 뒤 해당 기본 예제만 갱신하였다. 일반 배포 스크립트의 기존 `main.py` 보존 규칙은 유지하였다.

## 수행한 작업과 검사

- Release C# 단위 테스트 48개, Python 3.13.18·3.10.9 단위 테스트 각각 30개, 웹 테스트 11개가 통과하였다.
- 최초 통합 실행은 34개 중 26개 통과·8개 실패였다. 변경 전 테스트가 1단원의 자동 완료를 기다려 타임아웃이 났고 이후 7개 검사가 실행 중 상태 때문에 연쇄 실패하였다. 1~5단원 테스트와 놀이 배포 테스트를 입력 후 상태 확인 방식으로 수정하였다.
- 수정한 통합 테스트의 재실행과 전체 놀이 배포 검사는 사용자 지시로 생략하였다. 진행 중인 기본 배포 검사와 브라우저 검증도 중단하였다. 최종 변경이 전체 통합·배포 검사를 통과한 것으로 표현하지 않는다.
- 브라우저 중단 전 1단원의 방향키 이동과 15단원의 키 유지 이동까지 관찰하였다. 전체 브라우저 검증 완료 결과는 아니다.
- 수정한 9개 단원의 예제·학생 코드·HTML·교안 시작 코드 대응은 각 담당 범위에서 확인하였다. 최종 전체 자료 검사를 다시 수행하지 않았다.
- 마지막으로 배포 스크립트를 실행하여 학생 폴더의 공통 실행부·지원 모듈을 갱신하였다. 이 작업은 배포이며 추가 테스트 실행이 아니다.

## 환경과 한계

Windows x64 개발 컴퓨터, .NET SDK 10.0.403, Python 3.13.18·3.10.9, Node.js 24.15.0을 사용하였다. C# 검사에는 온라인 취약성 정보 연결 실패인 `NU1900` 경고가 있었다. 별도 SDK 없는 컴퓨터에서는 실행하지 않았다. 과거 소리 기능 검증 기록은 당시 결과로 보존하며 현재 기능 목록으로 사용하지 않는다.
