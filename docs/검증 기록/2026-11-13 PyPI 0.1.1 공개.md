# BlackPy 0.1.1 공개 검증 기록

## 공개 범위

사용자의 Git·PyPI 갱신 요청에 따라 BlackPy 0.1.1을 공개하였다. 시작 시 PyPI에는 0.1.0만 존재함을 확인하였다. 이번 버전은 명령 목록 재구성, Box2D.NET 물리, C#의 독립된 최대 60Hz 갱신, 웹 텍스트 입력과 학생 Python 파일의 직접 실행을 포함한다.

릴리스 소스는 [4520661b7ebb71795c18b83b74c21a49e3bb21f0](https://github.com/dove-creative/blackpy/commit/4520661b7ebb71795c18b83b74c21a49e3bb21f0)이다. 해당 커밋을 main에 푸시하고 GitHub Actions의 전체 검증을 통과한 뒤, 동일 커밋에서 expected_version=0.1.1과 publish=true로 공개 실행을 시작하였다.

공개용 설명과 사용 안내의 미공개 상태 문구를 0.1.1 기능 기준으로 정리하였다. 별도 사용자 설계 원본인 docs/BlackPy - 스토리보드.drawio와 samples/02-keyboard/고양이.py의 마지막 빈 행 변경은 릴리스 커밋에 포함하지 않고 작업 폴더에 보존하였다.

## CI에서 보완한 관측 기준

첫 [사전 실행](https://github.com/dove-creative/blackpy/actions/runs/43265802576)은 독립 이동 검사의 고정 450ms 대기 뒤 이동량 판정에서 실패하였다. [두 번째 실행](https://github.com/dove-creative/blackpy/actions/runs/43267225113)의 추가 진단에서는 일반 이동 약 396.7과 서로 다른 장면 120개가 확인되었다. 그러나 검사 시작 장면에서 공의 높이가 이미 -217.819였으며 바닥까지 남은 거리는 약 66.2로, 추가 낙하 70이라는 조건이 불가능하였다.

이동 등록·공의 초기 위치 복원·장면 표식을 같은 C# 요청으로 전달하고 응답 뒤 Python을 native time.sleep으로 정지하도록 테스트를 보완하였다. 실행 전에 관측기를 연결하고 표식이 유지된 장면들로 독립 진행을 판단한다. 요구 이동량·낙하량·서로 다른 장면 수는 유지하며 stdout 전달과 검사 프로세스의 대기 시점에 의존하지 않는다.

[세 번째 실행](https://github.com/dove-creative/blackpy/actions/runs/43268398416)에서 보완한 이동 검사는 통과하였으나 접촉 검사의 고정 1050ms 대기 뒤 위치 판정이 실패하였다. 접촉 검사에도 같은 장면 표식을 적용하여 Python 정지 구간에서 다른 객체를 통과했는지, 그동안 접촉 함수가 실행되지 않았는지, 복귀 뒤 시작·종료 이벤트가 순서대로 각각 한 번 전달되는지를 확인하도록 변경하였다. 이후 사전 검증과 공개 실행 모두 통과하였다. 이 보완은 테스트에 한정하며 제품 코드는 변경하지 않았다.

## 공개 파일과 동일성

공개 페이지는 [PyPI blackpy 0.1.1](https://pypi.org/project/blackpy/0.1.1/)이다. PyPI의 실제 업로드 시각은 2026-11-12 17:40:24.713218 UTC, 한국 시각으로 2026-11-13 02:40:24.713218이다.

- 파일은 blackpy-0.1.1-py3-none-win_amd64.whl이다.
- 크기는 48,975,275바이트이다.
- SHA-256은 `e218fecb04fa6ca1c47bb6cba746ed5d9abc239d74391f0d3a2339c3050b9b12`이다.
- 공개 실행의 blackpy-wheel 아티팩트 ID는 13968931781이다.

공개 실행의 아티팩트를 내려받아 내부 wheel의 SHA-256을 계산하였다. 그 결과가 PyPI 버전 API의 파일 해시와 새 환경의 pip 다운로드 보고서 해시 모두와 일치하였다. Actions 아티팩트 ZIP의 해시와 내부 wheel의 해시를 구분하였다. 이전 로컬 검증 wheel의 해시를 공개 파일의 근거로 재사용하지 않았다.

대조 자료는 artifacts/pypi-release-0.1.1의 pypi-metadata.json, install-report.json, hash-verification.json과 actions 폴더의 실제 wheel이다.

## 공개 설치와 실행

Windows x64 개발 컴퓨터의 새 Python 3.13.18 가상환경에서 공개 PyPI 인덱스를 명시하고 캐시를 사용하지 않은 설치를 수행하였다. 설치 보고서의 다운로드 주소가 files.pythonhosted.org임을 확인하였다.

```powershell
python -m pip --isolated install --index-url https://pypi.org/simple --no-cache-dir --only-binary=:all: blackpy==0.1.1 --report install-report.json
```

설치된 CLI의 버전은 BlackPy 0.1.1이다. 설치 패키지로 새 프로젝트를 생성한 뒤 해당 가상환경의 Python으로 학생 코드를 실행하였다. 한글 명령·중력·무대 바닥 충돌, 키 입력에 따른 충격, 웹 input의 질문·답 반환을 실제 HTTP·WebSocket 연결로 확인하였다. 마지막 브라우저 연결을 닫으면 설치형 실행기가 정상 종료되었으며 학생 파일의 내용은 그대로 보존되었다. 공개 설치·실행 확인 5개 항목이 통과하였다.

결과는 artifacts/pypi-release-0.1.1/public-verification.json과 artifacts/test-results/pypi-0.1.1-public-verification.log에 보관하였다. 기본 Python 환경의 패키지는 변경하지 않았다.

## 확인 범위

공개 파일의 설치·실행은 실제 공개 PyPI를 사용하였다. Python 3.10, SDK가 없는 별도 컴퓨터, 실제 VS Code 버튼과 브라우저 canvas 표시 FPS는 이번 공개 검증에서 새로 확인하지 않았다. 독립 갱신의 로컬 60Hz 실측과 그 한계는 [독립 시뮬레이션 검증 기록](2026-11-13%20독립%20시뮬레이션.md)에 있다.
