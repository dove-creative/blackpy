# 0.1.12 캐릭터별 중력 배율

## 무대와 팔레트

Windows x64의 Edge에서 물리 탭을 열고 두 행을 각각 눌러 복사한 값이 `중력`과 `중력_설정(1)`인지 확인하였다. 같은 공에 무게 1, 위쪽 충격 4를 주고 발판에서 정지한 높이와 최고점의 차이를 측정하였다. 중력 배율이 1일 때 약 81, 0.5일 때 약 163 무대 단위 상승하였다.

Box2D 계산에서 한 물체의 중력을 바꾸었을 때 다른 물체의 낙하가 독립적으로 유지되었고, 무중력에서도 이전에 얻은 속도와 새 충격이 반영되었다. 정지한 공에 중력을 다시 적용하자 낙하를 재개하였다. 기존 설정의 기본값은 1이며 재시작 후 프로젝트의 초기 배율로 복원되었다.

## 배포물

.NET 테스트 155개, Python 테스트 132개, 실행부 통합·샘플·웹 테스트 89개, wheel 설치·편집기·런처·직접 실행 테스트 31개가 통과하였다. 기존 프로젝트를 여는 두 설치 테스트에서도 프로젝트 정보에 새 기본값 `gravity: 1`이 포함되는지 확인하였다.

Release 빌드와 의존성 검사, 폴더 배포 검사 및 Twine의 엄격한 검사에 통과하였다. wheel에 담긴 실행부 DLL, Python 물리 명령, 팔레트와 편집기 안내가 검증본과 바이트 단위로 일치하였다. 검증한 wheel의 SHA-256은 `356e35689a1b895382d48ba37df10ea2e31d9cc0a675f1c342bc567cbcbdec5c`이다.

uv 관리 Python의 사용자 설치, VS Code의 pygame 가상환경, Anaconda의 사용자 설치에 같은 wheel을 적용하였다. 세 환경에서 각각 0.1.12 버전을 확인하고 학생 파일을 직접 실행하였다. 모두 콘솔에 0.5를 출력하였고, 발판에서 약 162.8 무대 단위만큼 상승한 뒤 다시 착지하였다.
