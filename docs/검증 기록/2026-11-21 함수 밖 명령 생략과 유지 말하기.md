# 함수 밖 명령 생략과 유지 말하기 검증

## 변경

학생 파일의 함수 밖에서는 함수 정의, 대입·증감 대입·주석 대입과 import만 실행한다. 명령 호출과 if·for·while 등 그 밖의 문장은 구문 분석 직후 안내 없이 제거한다. 함수 밖의 class와 async def는 기존 오류로 안내한다. 수업에서 '들여 쓴 줄만 이벤트에 들어간다'는 설명과 실제 동작을 맞추기 위한 변경이다.

유지 이벤트(`키_누름_중`·`자신_클릭_중`·`닿는_중`)에서 시간을 생략한 말하기는 그 호출의 키·포인터·접촉이 이어지는 동안 표시하고, 끝난 갱신에서 바로 지운다. 이전에는 마지막 호출부터 1초 동안 남았다. 시간을 지정한 유지 호출은 기존처럼 그 시간 동안 표시하고 `시간=None`은 계속 표시한다. 유지 중 접촉 목록이 바뀌어도 말풍선이 깜박이지 않도록 원인의 세대는 비교하지 않는다.

BlackPy 버전은 0.1.8 그대로이며 공개하지 않았다. 함수 밖의 `물리_설정`·`좌표로`·`print` 등을 준비 코드로 쓰던 테스트는 시작 이벤트 또는 `_ = ...` 대입으로 옮겼다.

새 Python 테스트는 함수 밖 명령·제어문의 생략과 대입·import·함수 정의의 실행, 함수 밖 class·async def 오류, 키·클릭·접촉 유지 말하기의 즉시 삭제, 여러 키 중 말한 키의 해제, 시간을 지정한 유지 호출을 확인한다. 새 이벤트 통합 테스트는 실제 실행부에서 키를 1.5초 누르는 동안 말풍선이 남고 떼면 사라지는지, 함수 밖 명령은 건너뛰고 대입한 위치는 적용되는지 확인한다.

처음 실행에서는 `01-movement`의 사각형 이동 검사가 실패하였다. 작업 폴더의 `samples/01-movement/고양이.py`가 커밋되지 않은 로컬 수정으로 바뀌어 있었기 때문이다. 이 파일을 커밋된 원본으로 되돌린 뒤 샘플 6개를 다시 실행하여 모두 통과하였다.

## 변수 블록 모음

블록 모음에 '변수' 분류를 추가하였다. '질문하고 값 입력받기' 카드는 숫자로 받는 `값 = int(input("값 입력"))`과 문자로 받는 `값 = input("값 입력")`을 복사하며, 주변 분류의 입력 카드는 제거하였다. 전역 변수 만들기와 함수 분류는 다음 작업으로 남겼다. 웹 단위 테스트는 변수 카드의 두 줄과 주변 분류의 입력 제거, 실제 화면의 7개 분류와 변수 행 복사를 확인하며 38/38 통과하였다.
