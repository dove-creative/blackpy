# 회전 충돌과 트리거 검증

## 변경

0.1.7은 방향에 맞춘 사각 충돌 범위와 명령 회전 차단을 제공한다. 자동 각운동은 잠근다. 기본 충돌 객체끼리 서로 통과하지 않으며 `물리_설정(모드, 트리거=False)`와 JSON `trigger`로 통과·접촉 여부를 지정한다. 어느 한쪽이 트리거이면 차단을 생략하고 접촉을 유지한다.

유지 이벤트의 전진은 변화하는 방향을 따라가며, 같은 호출에서 절대 방향을 먼저 정한 기존 방향키 이동은 화면 기준 벡터로 유지한다. Python이 정체되어도 C#이 회전·이동을 계속 처리한다.

기존 미커밋 작업인 캐릭터별 프로젝트 폴더 정리, 파일 단독 편집 안내, 공통 팔레트, 배경 명령 무시, 말하기 인자·시간, 뒤집기와 프로젝트 이미지도 함께 검증하였다.

## 로컬 검증

Windows x64, .NET SDK 10.0.404, Python 3.13, Node.js 24.15.0에서 실행하였다.

- C# 150개, Python 109개 통과이다.
- 이동·이벤트·물리·독립 시뮬레이션 통합 29개 통과이다.
- 웹 36개, 샘플 6개, 텍스트 입력 8개, 브라우저 수명 3개 통과이다.
- 폴더 배포 11개 확인 항목 통과이며 재배포 시 학생 파일 보존을 확인하였다.
- wheel 설치·제거, 편집기, 샘플 진입점, 직접 실행은 총 31개이다. 새 trigger 필드의 기본값을 기대값에 반영하였고, 직접 실행 11개를 재검증해 통과하였다. 나머지 20개는 앞선 실행에서 통과하였다.
- 새 0.1.7 wheel의 빌드와 메타데이터 검사를 통과하였다.

원래 통과를 가정하던 이동 테스트는 물리 없음, 통과 접촉 테스트는 트리거를 명시하였다. 회전한 객체의 바닥 도착 위치는 회전 사각형의 높이로 검증한다. 기본 고체 차단, 양쪽 트리거, 회전 직사각형 접촉, 막힌 회전과 반대 방향 탈출은 별도 C# 검증으로 유지한다.

## 범위

물리 검증은 실제 Box2D.NET과 배포 실행부를 사용한다. SDK가 없는 별도 장비와 브라우저 실제 표시 FPS는 측정하지 않았다. 로컬 테스트의 NuGet 취약성 조회 경고는 캐시된 복원 정보에서 발생했으며 테스트 실패는 아니다. 공개 배포와 실제 사용 환경 설치 결과는 [0.1.7 공개와 설치](2026-11-14%200.1.7%20공개와%20설치.md)에 기록하였다.
