# 학생 프로젝트 폴더 정리 검증 기록

## 목적과 변경

학생용 프로젝트의 바깥에는 학생이 편집하는 Python 파일만 두고, 설정·편집기 안내·시작 도구·설명서를 `_blackpy` 폴더에 모은 작업이다. 샘플 6개와 새 프로젝트 원본에 적용하였다. 폴더 배포본의 실행부는 `_blackpy/_runtime`, 실행 진입점은 `_blackpy/시작.exe`이다. 샘플 시작 도구는 `_blackpy/시작.pyw`이다.

실행부·설치형 명령·학생 파일 직접 실행·샘플 실행기가 새 설정 위치를 읽도록 보완하였다. 학생 파일의 상대경로 기준은 계속 프로젝트 바깥이며 새 설정과 기존 바깥 설정이 함께 있으면 `_blackpy/project.json`을 우선한다. 기존 바깥 project.json 형식도 지원하며 기존 배포 목적지에 다시 배포할 때는 설정·학생 파일·기존 실행 위치를 자동 이동하지 않는다.

사용자의 버전 형식 정정에 따라 현재 버전은 접미사 없는 0.1.3이다. 앞으로도 개발·공개 구분 없이 숫자.숫자.숫자 형식만 사용하도록 AGENTS와 개발 안내에 반영하였다. PyPI 공개·Git 커밋·푸시는 이번 작업에서 수행하지 않았다.

## 자동 검증

2026-11-13 KST의 Windows x64 개발 컴퓨터에서 .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0, PowerShell 7.6.9, Pyright 1.1.414를 사용하였다. 학생 파일은 임시 복사본으로 검사하였다.

| 검증 | 결과 |
| --- | --- |
| 고정 NuGet 패키지 | 2개 검증 통과이다. |
| C# | 131/131 통과이다. |
| Python | 89/89 통과이다. |
| 실행 통합·브라우저 수명 | 36/36 통과이다. |
| 샘플 | 6/6 통과이다. |
| 웹 | 33/33 통과이다. |
| 설치형·편집기·샘플 실행기·직접 실행 | 31/31 통과이다. |
| 배포 | 별도 11개 항목 통과이다. |

합계는 326/326이다. 새 위치의 설정으로 바깥 학생 파일을 실행하는 동작, 바깥 설정의 호환성, 새 폴더의 GUI 실행과 반복 배포 시 기존 학생 파일·설정 보존을 확인하였다. 실행 명령과 로그는 artifacts/layout-0.1.3/validate.ps1, local-results.json과 각 단계의 로그에 있다. 제한된 실행 환경에서 먼저 시작한 Python 단위 검사는 진행되지 않아 중단하였고, 이후 프로세스 실행 권한이 있는 환경에서 전체 검사를 수행하여 통과하였다.

실제 Anaconda 설치 확인 중 pip가 설치 원본에 만든 `__pycache__`를 새 학생 프로젝트에 복사하는 문제를 발견하였다. 프로젝트 생성 시 캐시와 pyc 파일을 제외하도록 수정하고 기존 프로젝트 생성 검사에 캐시 복사 방지 단언을 추가하였다. 수정 후 Python 명령 검사 7/7과 최종 wheel의 설치 관련 검사 31/31을 다시 수행하여 통과하였다. 로그는 cache-regression.log와 final-installed.log이다.

## 로컬 설치와 보존 확인

최종 wheel을 Anaconda Python 3.10.9 사용자 환경에 설치하여 BlackPy 0.1.3임을 확인하였다. 새 프로젝트의 바깥에 학생 Python 파일과 `_blackpy`만 생성되는지, 학생 파일 직접 실행·공의 낙하·발판 충돌·스페이스 충격·마지막 연결 종료와 파일 보존을 5개 확인 항목으로 검사하여 통과하였다. 같은 Python의 폴더 밖 파일 분석도 오류·경고가 모두 0개이다. 결과는 anaconda-verification.json과 anaconda-editor-analysis.json에 있다.

원래 물리 샘플의 학생 파일 3개와 옮긴 설정·안내 파일 2개의 SHA-256은 이동 전 기록과 모두 일치하였다. 기존 키보드 예제의 학생 편집과 설계 원본은 보존하였다. 샘플 설명서를 옮긴 뒤 상대 링크도 확인하였다.

- wheel은 artifacts/wheels/blackpy-0.1.3-py3-none-win_amd64.whl이다.
- 크기는 48,977,454바이트이다.
- SHA-256은 `1e05b03b2e9c1195e69b30126053122eb35e0e357f520318e70d96e7dee23f0b`이다.
- Twine strict 검사를 통과하였다.
- 이전 접미사 버전 wheel은 최종 버전 설치·실행 확인 후 제거하였다.

## 미검증 범위

사용자가 나중에 직접 화면을 확인하겠다고 한 요청을 유지하여 추가 화면 조작은 수행하지 않았다. 실제 VS Code 화면과 SDK가 없는 별도 컴퓨터는 이번 작업에서 검사하지 않았다. 새 폴더 배치는 0.1.3이 필요하며 PyPI 공개 전에는 로컬 wheel을 사용한다.
