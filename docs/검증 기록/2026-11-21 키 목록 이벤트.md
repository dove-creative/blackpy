# 0.1.10 키 목록 이벤트

## 실행 결과

Windows x64에서 .NET 테스트 151개, Python 테스트 130개, 실행부·브라우저 통합 테스트 43개, 샘플·웹 단위 테스트 44개, wheel 설치·편집기·런처·직접 실행 테스트 31개가 통과하였다. 의존성 고정, 폴더 배포, Twine 엄격 검사도 통과하였다.

갱신당 한 번의 호출, 여러 객체가 받는 키 목록의 독립성, 단일 키 해제와 전체 입력 초기화를 확인하였다. 독립 시뮬레이션에서는 키 조합이 바뀌었다가 원래 조합으로 돌아와도 이전 이동 명령이 재개되지 않았다.

## 설치본 실행

uv 관리 Python 사용자 설치, VS Code pygame 가상환경, Anaconda 사용자 설치에서 학생 파일로 무대를 실행하였다. 각 환경에서 두 키를 함께 누른 채 첫 번째 조건 우선, 같은 세기의 상쇄, 다른 세기의 이동을 확인하였다. 한 키만 놓으면 나머지 키의 이동이 계속되었다. 자동차로 벽에 부딪힌 뒤 우회하여 출구 트리거에 닿는 동작도 확인하였다.
