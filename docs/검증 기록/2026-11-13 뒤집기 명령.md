# 뒤집기 명령 검증 기록

## 변경 범위

`뒤집기("가로")`는 캐릭터 그림을 좌우로, `뒤집기("세로")`는 위아래로 뒤집는다. 두 축은 독립적으로 토글되며 같은 축을 두 번 호출하면 원래 모양으로 돌아온다. 위치·방향·이동·물리 상태는 바꾸지 않고 이름표와 말풍선도 뒤집지 않는다. 배경에서는 무시하고 새 실행에서는 두 축을 초기화한다.

명령 모음의 움직임 분류에서 오른쪽 돌기 다음에 뒤집기를 배치하였다. Python 런타임, C# 장면 전달·독립 시뮬레이션, Canvas 렌더러, 편집기 안내와 샘플 안내 파일을 동기화하였다. 버전은 0.1.5이다.

## 자동 검증

2026-11-13 KST, Windows 개발 컴퓨터에서 실행하였다. `scripts/Verify-Dependencies.ps1`, `dotnet test`, Python unittest 전체 탐색, 폴더 배포, 웹·실행 통합·배포·wheel·편집기·실행기 검사를 순서대로 수행하였다. .NET 빌드와 배포는 서로 겹치지 않게 실행하였다.

| 검증 | 결과 |
| --- | --- |
| 고정 NuGet 의존성 | 2개 통과 |
| C# | 133/133 통과 |
| Python | 108/108 통과 |
| 웹 | 35/35 통과 |
| 통합·샘플·브라우저 수명 | 45/45 통과 |

일반 자동화 테스트는 합계 352개이다. 뒤집기의 축별 복원, 잘못된 인자의 상태 보존, 이동·물리와의 분리, 배경 무시, 장면 복사·직렬화·독립 갱신, 렌더러의 그림만 반전하는 동작과 명령 배치를 포함한다. 실행 명령과 로그는 `artifacts/test-results/verify-flip.ps1` 및 `flip-*.log`에 있다.

NuGet 취약성 정보 서버에 접근하지 못한 NU1900 경고가 있었으나 패키지 해시 검사와 빌드·테스트는 통과하였다.

## 로컬 설치와 수업 실행부

검증한 동일 wheel을 다음 세 환경에 설치하였다.

- 터미널의 uv 관리 Python 3.13: 사용자 site-packages
- VS Code 기본 pygame 가상환경
- 수업에서 사용한 Anaconda Python 3.10: 사용자 site-packages

각 환경에서 `python -m blackpy --version`이 0.1.5임을 확인하고, 새 프로젝트의 학생 Python 파일을 직접 실행하였다. 가로·세로 토글, 세로 두 번 복원, 뒤집은 상태의 음수 이동, 방향·말풍선 유지, 배경 무시, 다시 시작 시 초기 위치·뒤집기 상태 복원을 실제 HTTP·WebSocket 실행으로 검사하였다. 세 환경 모두 통과하였으며 결과는 `artifacts/test-results/flip-local-install.json`에 있다.

수업 저장소의 연결 배포 스크립트로 오리엔테이션 `실습/_blackpy/_runtime`을 갱신하였다. 학생 코드·설정은 유지하고 배포 과정이 추가한 미사용 기본 자동차 파일만 원본과 해시를 대조하여 제거하였다. 활성 학생·교사용 자동완성 안내 22개도 새 API와 동기화하였다.

- 파일: `artifacts/wheels/blackpy-0.1.5-py3-none-win_amd64.whl`
- SHA-256: `cd66b2126f90bb174172ab92ad91d51bd12b37c84aadeb51593f0fdb8e0f56eb`

## 교재 확인

오리엔테이션 블랙파이 본수업 21쪽에 클릭할 때마다 가로로 뒤집는 시연과 세로 뒤집기 설명을 추가하였다. 본수업은 총 28쪽이다. 두 익힘책의 귀환 장면은 회전 없이 가로로 뒤집은 뒤 음수 거리로 이동한다. 배달부는 귀환 후 1초 뒤 원래 모습으로 복원하여 다음 클릭도 같은 모습으로 시작한다.

학생 HTML 5개의 폴더 연결 56개와 267개 화면 배치, 복사·힌트·정답·새로고침 초기화 검사를 통과하였다. 배달부의 마지막 수정 후에도 해당 익힘책의 30개 배치를 다시 확인하였다. 학생 Python 파일 33개는 변경 전 해시와 일치한다.

실제 교사용 프로젝트의 임시 복사본을 배포 실행부로 실행하였다. 배달부는 두 번 연속 클릭했을 때 각각 x=160까지 원래 모습으로 이동하고, 가로로 뒤집은 상태로 x=0에 돌아온 뒤 원래 모습으로 복원하였다. 방향은 계속 0도이며 키 입력 말하기도 유지된다. 간식 가게는 가게 위치 (160, -60)에서 300·3·1000을 입력받아 총금액 900원·거스름돈 100원을 안내하고, 집 (-160, -60)으로 돌아와 가로 뒤집기 상태와 방향 0도를 유지하였다.

Edge 화면에서 가게로 갈 때 오른쪽, 귀가할 때 왼쪽을 보는 고양이와 정상 방향의 말풍선·이름표를 확인하였다. 브라우저 오류는 없었다. 실행 결과와 화면은 `artifacts/test-results/flip-teacher-projects.json` 및 같은 접두사의 PNG에 있다.

## 검증 범위의 한계

개발 컴퓨터의 실제 설치·명령줄 직접 실행을 검증하였다. VS Code 실행 버튼을 직접 조작하거나 SDK가 없는 별도 컴퓨터에서 실행하지는 않았다. PyPI 업로드와 Git 커밋·푸시는 수행하지 않았다.
