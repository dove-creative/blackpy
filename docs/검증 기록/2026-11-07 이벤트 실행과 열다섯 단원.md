# BlackPy 이벤트 실행과 열다섯 단원 검증 기록

이 문서는 2026-11-07에 수행한 실행 코드 고정, 매직 함수 입력 처리와 15개 놀이 단원 배포의 검증 결과이다.

## 변경 범위

- 시작할 때 저장된 `main.py`의 바이트를 고정하고, 실행 중 저장한 변경은 다음 시작·다시 시작에 적용한다.
- `클릭`, `키누름`, `키뗌`, `마우스이동` 함수를 원래 정의 순서에 따라 등록하고, 일반 코드와 별도 이벤트 작업자에서 실행한다. 이벤트 함수끼리는 순서대로 실행한다.
- 입력 좌표·키 상태, 접촉·표시, 점수, Windows 음 재생과 종료 API를 추가한다.
- 6~15단원 예제와 학생 HTML·교사용 Markdown을 추가하고, 실행부와 지원 모듈을 배포한다.

이벤트 통합 검사는 일반 코드의 무한 반복 중 콜백 실행, 저장 후 현재 실행본 유지와 재시작 반영, 실제 실행본의 오류 파일·줄, 입력 검증·순서·상한, 이전 실행 차단, 중지·연결 종료를 포함한다. Python 단위 검사는 함수 정의 순서와 기본 인수, 잘못된 매직 함수 선언, 출력 보존과 비데몬 스레드가 있는 실행의 종료도 포함한다.

배포 테스트는 임시 복사본을 사용하였다. 두 차례 배포 후 수정해 둔 기본·15개 놀이 `main.py`가 바이트 단위로 보존됨을 확인하였다. 보고서는 `artifacts/test-results/deployment-verification.json`과 `activity-deployment.json`이다.

## 실제 화면 검사

- 학생 2부 목차에서 15개 단원 링크와 기본 실행 안내를 확인하였다.
- 10단원 학생 자료의 예상 답 확인, 전체 코드 복사, 체크 목록과 완료 표시를 조작하였다. 새로고침 후 답·완료·체크 표시가 초기화되었고 가로 넘침이 없었다.
- 10단원 웹 무대에서 실제 클릭 6회로 목표 종료를 확인하고, 다시 시작·중지를 확인하였다.
- 12단원 웹 무대에서 방향키로 별을 3번 만나 목표 종료를 확인하였다.
- 검사한 학생 자료·두 무대의 브라우저 오류·경고 로그는 없었다. 학생 자료 미리보기 서버의 선택 사항인 `favicon.ico` 요청에는 404가 있었으며 수업 내용 로딩에는 영향이 없었다.
- 검사에 사용한 브라우저 탭과 임시 HTTP 서버·BlackPy 호스트는 종료하였다.

## 환경 오류와 검증 한계

첫 샌드박스 C# 테스트는 테스트 호스트 연결 제한으로 실행을 시작하지 못하였다. 로컬 통신이 가능한 환경에서 다시 실행하여 48개가 통과하였다. NuGet 취약성 서비스 연결 경고 `NU1900`은 기록된 경고이며 테스트 실패는 없었다.

SDK가 없는 별도 컴퓨터에서는 실행하지 않았다. 개발 컴퓨터에서 PATH와 `DOTNET_ROOT`를 제한한 상태로 동봉 런타임의 실제 로딩을 확인한 결과이다. 모든 학생 자료를 브라우저에서 하나씩 시각 검사한 것은 아니며, 실제 화면 검사는 위에 적은 대표 자료·무대에 한정한다.

음 재생 함수가 완료되는 것은 확인했으나 스피커에서 소리가 들리는지 직접 청취하지 않았다. 14단원은 배포 검사에서 받침대 이동·공 받기 1회·중지까지 확인했으며, 5점 달성까지의 전체 플레이는 수행하지 않았다.

고정 대상은 `main.py`이며 가져온 외부 Python 모듈까지 복사하는 기능은 아니다. 접촉 검사는 회전을 반영하지 않는 사각형 겹침이며, 이벤트 콜백은 하나의 작업자에서 순서대로 처리한다.

외부 자료의 공백 검사는 이번 변경과 관계없는 기존 문서의 공백 3건을 보고하였다. 해당 기존 파일은 수정하지 않았다.
