# 파일 단독 편집 안내 검증 기록

## 목적과 변경

VS Code에서 프로젝트 폴더 없이 학생 Python 파일만 열어도 BlackPy 명령을 인식하도록 pip 설치형을 보완한 작업이다. 공개된 0.1.2와 같은 버전으로 서로 다른 wheel을 만들지 않도록 개발 버전 0.1.3.dev1을 사용하였다. PyPI 공개·Git 커밋·푸시는 수행하지 않았다.

프로젝트 안내 파일과 같은 원본을 패키지의 `_editor/__builtins__.pyi`에 포함하고 기존 `.pth`에 정적 상대경로를 추가하였다. 선택한 Python 환경의 검색 경로에서 분석기가 안내를 찾으므로 학생 코드의 import와 VS Code 설정 변경이 필요하지 않다. 일반 Python의 실제 내장 함수는 변경하지 않는다. 기존 프로젝트·사용자 정의 안내 파일은 우선하며 설치·재설치·제거가 이를 덮어쓰거나 삭제하지 않는다.

환경 안내는 같은 Python으로 편집하는 일반 Python 파일에도 BlackPy 이름을 제공한다. 실제 한글 명령 실행은 기존과 같이 BlackPy 프로젝트에서만 제공한다. 학생 명령과 예제 내용은 바꾸지 않았으며 수업 준비에서 BlackPy를 설치한 Python을 선택하는 조건은 유지된다. pip 설치형의 폴더 열기 단계만 선택 사항이 된다.

검증용 wheel 경로는 소스의 현재 버전에서 정하도록 바꾸어 개발 버전도 설치·직접 실행·샘플 검증에 사용할 수 있게 하였다.

## 환경과 자동 검증

2026-11-13 KST의 Windows x64 개발 컴퓨터에서 .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0, PowerShell 7.6.9, Pyright 1.1.414를 사용하였다. 파일 단독 분석은 Anaconda Python 3.10.9에서도 별도로 확인하였다. 설치된 Pylance 2026.4.1이 사용하는 Pyright 버전도 1.1.414이다.

| 검증 | 결과 |
| --- | --- |
| 고정 NuGet 패키지 | 2개 검증 통과이다. |
| C# | 130/130 통과이다. |
| Python | 88/88 통과이다. |
| 실행 통합·브라우저 수명 | 36/36 통과이다. |
| 샘플 | 6/6 통과이다. |
| 웹 | 33/33 통과이다. |
| 설치형·편집기·샘플 진입점·직접 실행 | 30/30 통과이다. |
| 배포 | 별도 10개 항목 통과이다. |

합계는 323/323이다. 전체 실행 명령과 단계별 결과·로그는 artifacts/loose-file-editor/validate.ps1, local-results.json과 각 단계의 로그에 있다. 새 임시 배포본에서 만든 wheel은 Twine strict 검사를 통과하였다.

새 편집기 검사는 프로젝트와 무관한 빈 디렉터리를 분석 기준으로 두고, 프로젝트 안내 파일이나 VS Code 설정이 없는 학생 파일을 분석한다. 패키지 설치 후 명령과 print·len·int의 진단이 0개임을 확인하였다. 오타·일반 미정의 이름은 이름 오류 2개, 잘못된 무게 인자는 타입 오류 1개로 계속 검출된다. 기존 Python 환경의 사용자 정의 안내가 재설치·제거 후에도 유지되고 우선 적용되며, 패키지를 제거하면 `_editor` 안내와 검색 경로도 사라지는 것을 확인하였다.

Python 3.10.9의 독립 실험에서도 기존 물리 예제 복사본의 이름 오류 11개가 환경 안내 등록 후 0개가 되었다. 원본 학생 파일은 수정하지 않았다.

## 로컬 적용

현재 Anaconda 사용자 환경에 로컬 wheel을 설치하여 BlackPy 0.1.3.dev1로 갱신하였다. 같은 Python을 지정하여 프로젝트 폴더 밖의 물리 예제 복사본을 분석한 결과 오류·경고가 모두 0개였다. 일반 Python의 실제 builtins에 물리 명령이 추가되지 않았음도 확인하였다. 설치 시 사용자 Scripts 폴더의 PATH 안내가 표시되었으며 버전 확인은 같은 Python의 `-m blackpy`로 수행하였다.

- wheel은 artifacts/wheels/blackpy-0.1.3.dev1-py3-none-win_amd64.whl이다.
- 크기는 48,977,306바이트이다.
- SHA-256은 `2ff09c95a244008d1b9242851b282ec969cef2b03ff19f9c6189c10c8d2ffbcf`이다.
- 적용·분석 결과는 anaconda-install.log와 anaconda-editor-analysis.json에 있다.

## 미검증 범위

같은 날 후속 요청에서 버전 접미사를 제거하고 0.1.3으로 전환하였다. 현재 적용 상태와 새 프로젝트 폴더 구성은 [학생 프로젝트 폴더 정리 검증 기록](2026-11-13%20학생%20프로젝트%20폴더%20정리.md)에 있다. 위 버전·wheel 수치는 이 문서를 처음 검증한 당시의 기록이다.

실제 VS Code 창을 열어 확인하려던 단계에서 사용자가 컴퓨터 조작을 중단하고 나중에 직접 확인하겠다고 요청하였다. 이후 화면 조작은 하지 않았다. 실제 Pylance 화면의 경고 소멸·자동 완성은 사용자 확인 대상으로 남아 있으며 자동 분석 통과와 구분한다. 별도 SDK 없는 장비와 다른 편집기는 이번 검증에 포함하지 않았다.
