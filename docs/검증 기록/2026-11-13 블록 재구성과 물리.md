# 블록 재구성과 물리 검증 기록

## 변경 범위

명령 목록을 이벤트·움직임·물리·생김새·계산·주변으로 재구성하였다. 변수·함수 만들기는 보류하였다. 값·명령·이벤트 행을 구분하고, 방향 보기와 크기 변경을 나누며, 이름 변경과 닿은 객체 목록을 추가하였다. 기존 input과 프로퍼티 대입 기능은 유지한다.

물리 계산은 MIT 라이선스의 Box2D.NET 3.1.654를 C# 실행부에 연결하였다. 없음·충돌만·물리 모드, 질량, 한 번의 충격, 정지, 중력, 사방 경계 벽과 접촉을 지원한다. 물체의 자동 회전은 잠그고 회전하지 않는 사각 충돌 범위를 사용한다. 물리 객체의 앞으로 이동은 장애물에 막히며, 명령 완료 후 다음 문장에서 실제 위치를 읽는다. 학생 Python에 물리 패키지나 import를 요구하지 않는다.

Python과 C# 사이에서 이동·설정 명령 순서를 보존하고, 물리 응답을 기다리는 동안 발생한 새 이동·절대 배치를 유지한다. 실행을 중지하거나 다시 시작하면 이전 물리 세계를 정리한다. 이름 변경은 내부 객체 식별자와 학생 파일명을 유지한다.

물리 예제 06-physics, 편집기 명령 안내, 사용·구현·테스트 문서와 폴더 배포·wheel의 라이선스 고지를 함께 갱신하였다. 작업 전부터 있던 입력·직접 실행·패키지 관련 변경은 보존하였다.

## 실행 환경과 산출물

2026-11-13 KST의 Windows x64 개발 컴퓨터에서 .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0, PowerShell 7.6.9, Pyright 1.1.414를 사용하였다.

폴더 배포본은 artifacts/physics-validation이다. wheel은 새 임시 배포본으로 생성한 artifacts/wheels/blackpy-0.1.1-py3-none-win_amd64.whl이며 크기는 48,960,201바이트이다. SHA-256은 `5fc9d2d55aca9f46f2c71898b87331b279c5c5263003c90750d1d2323a77f508`이다. Twine strict 검사를 통과하였다.

## 검증 중 발견과 보완

첫 통합 검사는 30/31이었다. 포커스 해제 콜백의 출력이 마지막 이동 장면보다 먼저 전송될 수 있는데, 기존 테스트가 출력 도착만으로 장면 갱신까지 완료되었다고 가정하였다. 해제 콜백의 실제 좌표가 장면에 반영될 때까지 기다린 뒤 150ms 동안 두 좌표가 정확히 유지되는지 검사하도록 보완하였다. 제품의 입력 해제 동작은 변경하지 않았으며 전체 통합 재실행에서 31/31을 확인하였다.

첫 설치형 검사는 16/29였다. 새 프로젝트 응답에 추가된 physics·mass 기본값과 새 샘플의 생략한 heading 기본값이 기존 기대값에 없었다. 프로젝트 정규화 기대값을 보완한 뒤 같은 최종 wheel로 29/29를 확인하였다.

샌드박스 안에서는 Python의 로컬 소켓 쌍 생성과 .NET 테스트 통신이 멈추는 환경 제약이 있었다. 해당 실행을 취소하고 로컬 통신을 허용한 환경에서 전체 검사를 수행하였다. 초기 NuGet 복원에는 DNS·서명 조회 네트워크 오류가 있었으나 캐시를 확보한 뒤 복원·빌드를 완료하였고, 최종 wheel 빌드의 복원도 성공하였다.

전체 diff 공백 검사에는 작업 전부터 존재하던 samples/02-keyboard/고양이.py의 마지막 빈 행 한 건이 남아 있다. 해당 학생 예제의 기존 변경은 수정하지 않았다.

## 화면 검증과 한계

실제 브라우저 화면 검증은 완료하지 못하였다. 브라우저 제어 공급자가 없고 in-app 브라우저도 사용할 수 없어 네이티브 Chrome을 시도했으나, 컴퓨터 제어 도구가 현재 URL을 신뢰성 있게 확인하지 못하여 조작을 중단하였다. BlackPy 페이지를 열지 못했으므로 화면 배치·작은 창·복사 버튼의 실제 조작 결과는 미확인이다. 과거 화면 확인 결과를 이번 변경의 검증으로 재사용하지 않는다.

화면 확인을 위해 만든 임시 프로젝트의 실행부는 종료하였다. 전체 테스트 뒤 프로세스 목록에서도 BlackPy 실행부와 관련 Python 자식이 남지 않았음을 확인하였다. Chrome에 복원된 기존 사용자 탭은 강제로 종료하지 않았다. 원본 샘플과 학생 파일은 직접 수정하여 테스트하지 않았다.

Python 3.10 실제 실행, SDK가 없는 별도 PC, 실제 VS Code 버튼과 운영체제 IME 조작은 이번 검증에 포함하지 않았다. 로컬 wheel 검증과 GitHub Actions·PyPI 공개는 구분하며, 커밋·푸시·업로드와 기본 Python 환경의 설치 교체는 수행하지 않았다.

## 수업 자료 영향

학생용·교사용 목차를 읽기 전용으로 확인하였다. 캐릭터별 코드와 input 중심의 목차에는 이번 물리 API가 아직 반영되지 않았고, 이전 자료에는 구형 Actor·stage 예제가 남아 있다. 새 수업에는 물리 예제의 세 모드, 순간 충격과 중력, 정지 뒤에도 낙하가 계속되는 의미, 회전하지 않는 사각 충돌 범위를 반영할 필요가 있다. 외부 자료는 이번 작업에서 변경하지 않았다.
