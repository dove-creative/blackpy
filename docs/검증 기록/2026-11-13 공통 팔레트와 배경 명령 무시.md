# 공통 팔레트와 배경 명령 무시 검증

## 변경 범위

- 객체 선택기를 제거하고 여섯 분류를 공통 명령 팔레트로 제공하였다. 캐릭터 전용 항목을 표시하고 무대 아래에는 모든 캐릭터의 이름·위치·방향을 표시한다.
- 배경의 캐릭터 전용 함수는 상태 변경·물리 요청·대기 없이 반환한다. 이동·회전과 이전 회전 이름, 좌표·방향·속도·크기·가시성, 물리·무게·힘·정지·이름 변경을 포함한다.
- 배경 접촉 이벤트는 등록하지 않는다. 말하기·기다리기·방송·조회와 일반 및 유지 이벤트는 정상 실행한다. 캐릭터 전용 상태 값의 읽기·직접 대입에 대한 기존 제약은 유지한다.
- 사용 안내·편집기 stub·README 화면을 동기화하였다. 기존에 100칸 네모 걷기로 수정된 샘플 코드를 보존하고 그 설명과 테스트를 현재 동작에 맞추었다.

## 검증 결과

2026-11-13 Windows x64 개발 환경에서 로컬 소스와 새 배포본으로 실행하였다.

| C# Release 테스트 | 131/131 통과하였다. |
| Python 전체 테스트 | 92/92 통과하였다. |

| HTTP·WebSocket·이벤트·물리·시뮬레이션·입력·브라우저 수명 | 37/37 통과하였다. |
| 실제 샘플 실행 | 6/6 통과하였다. |

자동 테스트는 총 330개이다. 최초 샘플 검사에서는 과거 160칸·완료 메시지를 기대한 검사가 실패하여 현재 샘플에 맞춘 뒤 여섯 샘플 전체를 다시 통과하였다. 실제 Windows 클립보드는 줄바꿈을 CRLF로 반환하므로 브라우저 검사는 줄바꿈만 정규화해 비교하였다.

## 환경과 범위

- Python asyncio와 실제 브라우저·프로세스 검사는 샌드박스 밖에서 실행하였다.
- .NET 복원 중 NuGet 취약성 피드에 접근하지 못하는 NU1900 경고가 있었으며 테스트는 통과하였다. 취약성 피드 조회 성공으로 해석하지 않는다.
- 초기 설치 검사는 임시 가상환경에서 로컬 wheel로 수행하였다. 이후 같은 날 사용자 요청에 따라 검증한 0.1.3 wheel을 이 PC의 터미널 기본 Python 사용자 패키지 경로와 VS Code의 pygame 가상환경에도 설치하였다. uv가 관리하는 기본 Python 디렉터리는 변경하지 않았다.
- 실제 두 사용 환경에서 설치 파일과 소스의 일치, 직접 실행 연결, 학생 파일 실행, 공통 팔레트 제공, 배경에서 캐릭터 전용 함수 무시와 정상 종료를 확인하였다. 결과는 로컬 `artifacts/test-results/local-install.json`에 기록하였다. PyPI 업로드는 수행하지 않았다.
- 배포 검사는 개발 PC에서 수행하였으며 SDK가 없는 새 Windows PC에서의 검증은 아니다. 별도 성능 측정은 수행하지 않았다.
