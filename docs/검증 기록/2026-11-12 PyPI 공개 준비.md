# PyPI 공개 준비 검증 기록

## 변경 범위

PyPI 공개 요청에 따라 패키지 설명을 `distribution/README.pypi.md`로 분리하였다. 저장소 상대 링크와 공개 전 상태 문구를 제외하고 설치·실행·편집기 지원·제약을 설명한다. 패키지 메타데이터의 readme 경로만 변경하였으며 실행 코드와 학생 파일은 변경하지 않았다.

## 환경과 결과

Windows x64, Python 3.13.18, Node.js 24.15.0, .NET SDK 10.0.404, PowerShell 7.6.9에서 실행하였다. build 1.6.1, Hatchling 1.33.0, Twine 6.2.0, Pyright 1.1.414를 사용하였다.

## 최종 배포 파일

- 파일: `artifacts/wheels/blackpy-0.1.0-py3-none-win_amd64.whl`
- 크기: 48,807,100바이트이다.
- SHA-256: `51f93ffa3c05d286b8bb41cdead8a3f68768915450c470d2098c5f3133c80af4`이다.

이 파일은 공개용 설명을 넣기 전의 로컬 설치 검증 파일을 대체한다. 실행 기능은 동일하며 새 파일 자체의 설치형 통합 검증을 다시 수행하였다.

## 공개 상태와 제한

준비 시점의 PyPI `blackpy` 프로젝트 조회는 404이다. 실제 등록 가능 여부는 업로드 성공으로 확정한다. 이메일 인증은 확인하였으며 계정의 2단계 인증과 업로드 인증을 기다리는 상태이다. 아직 공개 업로드나 공개 PyPI에서의 설치를 완료한 것은 아니다.

Python 3.10의 실제 실행, 별도 SDK 미설치 PC와 실제 VS Code·브라우저 UI 재검증은 수행하지 않았다. Pyright 및 HTTP·WebSocket 자동화 검증과 구분한다. 학생 HTML·교사용 교안과 Git 커밋·푸시는 변경하지 않았다.
