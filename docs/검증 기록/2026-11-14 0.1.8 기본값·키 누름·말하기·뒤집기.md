# 0.1.8 기본값·키 누름·말하기·뒤집기 검증

## 변경

- `앞으로`의 값을 생략하면 일반 이벤트에서 거리 100, 유지 이벤트에서 속도 1이다. 유지 이벤트의 `앞으로` 값은 속도이며 1은 일반 이동과 같은 초당 200이다. 속도 배율도 함께 곱한다. 돌기 명령 네 가지의 기본값은 90도이며 유지 이벤트의 돌기 값은 기존처럼 초당 각도이다.
- 키 이벤트 이름을 `키_누름`·`키_누름_중`·`키_누름_끝`으로 바꾸었다. 이전 `키_클릭` 계열 함수를 정의하면 실행 전에 새 이름과 줄 번호를 알리는 문법 오류로 안내한다. 웹 명령 목록·편집기 안내·샘플·문서를 함께 바꾸었다.
- `뒤집기`는 거울 반사로 모양과 바라보는 방향을 함께 뒤집는다. 가로는 θ를 `180 - θ`, 세로는 θ를 `-θ`로 바꾸며 그림은 진행 방향 축에 대해 반사한다. 장면 필드 `flipHorizontal`·`flipVertical`의 형식은 유지하고 반사 상태를 `flipVertical`로 전달한다.
- `말하기`의 `시간` 기본값은 1초이다. 시작과 일반 이벤트에서는 표시 후 기다렸다가 지우고 다음 줄로 진행한다. `시간=None`은 기다리지 않고 계속 표시하며 빈 내용은 바로 지운다. 유지 이벤트와 파일 초기화에서는 기다리지 않고 삭제 시각만 정한다. 남은 삭제 시각이 있으면 다른 이벤트가 없어도 실행을 유지한다.
- 웹의 시작·다시 시작 버튼은 요청을 보내기 전에 무대로 키보드 초점을 옮긴다. 입력 안내 문구를 바꾸었다.
- 웹 무대에 브라우저 탭 아이콘 `favicon.svg`를 추가하였다. 초록 바탕의 B 모양이며 수업 교재 HTML의 파란 책 아이콘과 구분된다.
- 샘플의 유지 이동 값을 속도로 바꾸고 긴 배경 안내는 5초 동안 표시한다. 말하기가 기다리므로 콘솔 기록은 말하기보다 먼저 출력하도록 순서를 바꾸었다. 버전은 0.1.8이다.

기존 기대값 중 유지 이동의 초당 거리는 같은 빠르기의 속도 값으로 바꾸었다. 실행 종료 후의 말풍선을 확인하는 검사는 `시간=None`을 사용한다. 방송 샘플은 마지막 말하기가 끝난 뒤 두 번째 방송을 보낸다. 같은 신호의 이벤트가 실행 중이면 재입력을 무시하는 기존 규칙 때문이다.

## 범위

.NET 복원 중 NuGet 취약성 정보 서버에 접근하지 못한 NU1900 경고가 있었다. 패키지 해시 검사와 빌드·테스트는 통과하였다. 실제 브라우저에서 버튼 초점과 뒤집은 그림을 눈으로 확인하지 않았으며 웹 단위 테스트의 결과와 구분한다. 이 기록의 검증에서는 프레임 성능 측정, PyPI 공개, 실제 사용 Python 환경의 설치를 수행하지 않았다. 공개와 설치 결과는 [0.1.8 공개와 설치](2026-11-14%200.1.8%20공개와%20설치.md)에 기록하였다.
