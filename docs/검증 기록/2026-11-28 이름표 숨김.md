# 이름표 숨김 검증 기록

## 변경 내용

BlackPy 0.1.17에 프로젝트별 이름표 표시 설정인 showLabels를 추가하였다. 기본값은 true이며 false인 프로젝트의 미리보기와 실행 화면에서 캐릭터 이름표를 그리지 않는다. 객체 이름, 이름을 사용하는 접촉 판정, 말풍선, 디스플레이는 유지한다.

## 환경과 결과

Windows x64, .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0에서 검사하였다. 기존 작업 폴더의 전역변수·디스플레이와 객체 함수 호출 변경을 보존한 상태에서 전체 테스트를 수행하였다.

자동 테스트는 합계 446개이다. 실행 명령은 Testing.md의 전체 테스트 순서를 따랐다. wheel은 준비된 packaging-venv의 `python -m build --wheel --no-isolation --outdir artifacts/wheels .`로 생성하였다. 로그는 artifacts/labels-*.log에 있다.

검증한 wheel은 blackpy-0.1.17-py3-none-win_amd64.whl이며 크기는 49,034,972바이트, SHA-256은 472bf52b94e6cb07c24450e3da9fe5f2de92335f9a694b4e63adc5d9288cc7ef이다. 로컬 설치만 수행했으며 PyPI에는 공개하지 않았다.

## 검증 경계

새 C# 테스트는 기본값과 false 설정의 직렬화, 객체 이름 보존을 확인한다. 새 웹 테스트는 같은 장면에서 기본 표시·숨김·다시 표시를 비교하고 말풍선이 남는지 검사한다. 실제 실행 장면을 설치본의 무대 렌더러와 네이티브 캔버스로 그려 이름표 제거와 말풍선 유지도 확인하였다. 브라우저를 조작하는 별도 화면 검증은 수행하지 않았다.

샌드박스의 로컬 통신 제약으로 처음 실행한 테스트는 중단하고 일반 실행 환경에서 전체 테스트를 다시 수행하였다. 설치본 확인 도구도 강제 종료 대신 마지막 연결을 닫은 뒤 정상 종료를 기다리도록 바꾸어 두 환경에서 재검증하였다.
