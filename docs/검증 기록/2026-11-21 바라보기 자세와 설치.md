# 0.1.9 바라보기 자세와 설치

## 동작과 화면

- 각도와 좌표로 왼쪽·오른쪽 대각선을 바라보기, 같은 각도 반복 지정, 정확히 위·아래를 향할 때 직전 반사 상태 유지, 바라본 뒤 오른쪽 돌기를 Python 테스트로 확인하였다.
- Windows x64의 Edge 헤드리스에서 설치된 런타임의 고양이를 0도와 180도로 그렸다. 180도 그림을 0도 그림의 좌우 반사와 비교한 RGB 절댓값 차이의 합은 1,616이고, 180도 회전과 비교한 합은 1,731,530이다. 발은 아래에 유지되고, 얼굴 위치가 오른쪽에서 왼쪽으로 바뀌었다.

세 인터프리터에서 0.1.9 버전을 확인하고 임시 학생 파일을 직접 실행하였다. 웹 무대에 `d → a → a → d` 입력을 보내 매번 30만큼 이동하고 왼쪽 자세가 유지되는지 확인하였다. 이어 좌표로 왼쪽 위를 바라본 뒤 135도 오른쪽으로 도는 동작과 무대 종료도 모두 통과하였다.
