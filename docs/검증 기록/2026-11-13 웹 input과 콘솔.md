# 웹 input과 콘솔 검증 기록

## 변경 범위

학생 스크립트의 input을 웹 무대 아래 질문·답 입력칸에 연결하였다. 파일 맨 위, 시작·일반 이벤트와 보조 함수에서 문자열을 반환하며 여러 질문은 요청 순서대로 표시한다. 빈 답·앞뒤 공백을 보존하고 int·float 변환을 사용할 수 있다. 이벤트의 입력 대기는 다른 이벤트와 이동을 막지 않는다. 유지 이벤트의 매 프레임 질문은 오류로 안내한다.

실행·질문 식별자를 함께 확인하여 중복·이전 실행 답을 차단한다. 중지·재시작·실행 종료 때 남은 질문을 정리하고, 초점 초기화와 답 제출이 겹쳐도 접수한 답을 보존한다. 초기화가 입력 조회 도중 끝나더라도 시작 이벤트를 조작 이벤트보다 먼저 예약한다.

웹의 로그 창 제목과 관련 안내를 콘솔로 변경하였다. 무대·콘솔·블록 모음의 기존 배치는 유지하였다. 답은 브라우저 저장소에 기록하지 않으며 학생 코드가 답을 출력한 경우에는 콘솔에 표시된다.

## 실행 환경과 산출물

2026-11-12~13 KST의 Windows x64 개발 컴퓨터에서 .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0, PowerShell 7.6.9, Pyright 1.1.414를 사용하였다.

폴더 배포본은 artifacts/blackpy이다. 최종 설치형 파일은 artifacts/wheels/blackpy-0.1.1-py3-none-win_amd64.whl이며 크기는 48,821,034바이트이다. SHA-256은 `4fbb750ceb7f20b3a1bc2abbae5d7be94685d86d2b5fdc2ed2575a4239680493`이다. wheel은 새 임시 배포본에서 빌드하고 Twine strict 검사를 통과하였다. 설치 검증은 임시 Python 환경에서 수행하였다.

테스트 러너 합계는 223/223이다. 최종 wheel 설치 검사 출력은 artifacts/test-results/text-input-packaging.log에 있다. 설명 문구 정리 후 wheel을 다시 빌드하고 설치형 26개 검사를 재실행하였다.

첫 .NET 테스트 시도는 사용자 NuGet.Config 읽기 제한으로 시작하지 못했고, 첫 배포 검사 시도는 Windows 프로세스 조회 권한 제한으로 중단되었다. 같은 코드를 정상 권한으로 재검증하여 통과하였다. 전체 작업 트리의 diff 검사에는 기존 samples/02-keyboard/고양이.py 마지막 빈 줄 경고가 남아 있으며 이번 변경 범위의 검사는 통과하였다.

## 브라우저 확인

실제 로컬 실행부를 in-app 브라우저에 연결하여 다음 항목을 확인하였다.

- 파일 맨 위의 질문 표시와 첫 입력칸 자동 초점이다.
- 한글 문자열을 Enter로 제출하고 콘솔에서 해당 출력을 확인하였다.
- 다음 질문에 120을 입력하여 답 보내기로 제출한 뒤 int 변환과 캐릭터의 120 이동, 정상 완료와 질문 숨김을 확인하였다.
- 다시 시작하면 첫 질문이 빈 입력칸으로 나타나며 입력 대기 중 중지하면 질문이 사라지는 것을 확인하였다.
- 콘솔 제목과 접근성 이름의 변경을 확인하였다.
- 기본 화면과 폭 480 화면에서 입력칸·버튼이 겹치지 않고 가로 넘침이 없음을 확인하였다. 임시 화면 크기 설정은 검증 뒤 해제하였다.

확인 화면은 [입력창과 콘솔](../../artifacts/test-results/input-console.jpg)에 있다. 한글 문자열은 자동 입력으로 확인하였으며 실제 운영체제 IME의 조합·확정 키 입력은 별도로 검증하지 않았다. IME 이벤트 처리는 웹 단위 테스트로 검증하였다.

## 수업 자료 영향과 한계

수업 자료를 읽어 영향을 확인하였다. 값·변수·사칙연산 단원에서 문자열 입력과 숫자 변환을 연결할 수 있으며 사용 예제는 Usage에 추가하였다. 학생 수업 자료와 목차는 이번 기능 추가에서 수정하지 않았다. 캐릭터의 읽기 전용 상태인 이름 대신 대답·학생_이름 같은 일반 변수를 사용해야 한다.

Python 3.10 실제 실행, SDK가 없는 별도 PC, 실제 VS Code 버튼 조작은 이번 검증에 포함하지 않았다. 직접 파일 실행은 임시 환경에서 명령줄로 검증하였다. 커밋·푸시·GitHub Actions 실행·PyPI 공개와 기본 Python 환경의 패키지 교체는 수행하지 않았다.
