# 디스플레이 검증 기록

## 변경 내용

BlackPy 0.1.15에 전역변수를 표시하는 디스플레이를 추가하였다. 프로젝트의 displays 목록으로 배치하며 별도 Python 파일이나 물리 객체를 만들지 않는다. 시작 전·중지 후 점수판을 누르면 무대 콘솔에서 변수 이름을 연결할 수 있다. 연결은 project.json에 저장하고 실행 중에는 변경을 거절한다. 없는 변수는 —로 표시하며 새 실행의 값은 학생 코드가 다시 초기화한다.

두 동전이 같은 동전_수 변수를 올리는 07-display 샘플과 사용자·구현·검증 문서를 추가하였다.

## 환경과 결과

Windows x64, .NET SDK 10.0.404, Python 3.13.18, Node.js 24.15.0에서 검사하였다.

0.1.15 범위의 자동 테스트는 합계 437개이다. .NET 복원에서 NuGet 취약성 서비스 접속 실패에 따른 NU1900 경고가 있었으나 빌드와 테스트는 통과하였다.

설치 파일은 blackpy-0.1.15-py3-none-win_amd64.whl, 크기는 49,034,306바이트, SHA-256은 e4a87abb0944e227ab34c85a7f14185d3325ace5ec965b58d312f95b030590bf이다. 로컬 설치만 수행하였으며 PyPI 공개는 하지 않았다.

## 동시 작업과 검증 경계

wheel 생성 뒤 같은 작업 폴더에서 별도의 0.1.16 개발이 시작되었다. 해당 작업이 배포용 명령 안내에서 방송하기를 제거하고 객체_구하기를 추가하면서, 작업 폴더를 읽는 기존 편집기 검사 두 개가 실패하였다. 이후 테스트 파일에도 새 API 검사가 추가되어 0.1.15 자료와 직접 비교할 수 없게 되었다.

다른 작업의 소스와 버전은 되돌리지 않았다. 0.1.15 wheel에서 기본 프로젝트를 추출하고 작업 시작 시점의 Editor.test.mjs 검사를 임시 파일로 복사하여, 프로젝트 입력 경로만 추출본으로 지정한 뒤 같은 검사 두 개를 실행하여 통과하였다. 이는 0.1.15 설치본의 검증이며 진행 중인 0.1.16 전체 소스의 통과를 의미하지 않는다.

## 실제 화면 확인

임시 샘플 복사본을 실제 실행부와 브라우저로 열어 다음 흐름을 확인하였다.

- 실행 전 점수판 클릭 시 콘솔 입력칸이 열리고 초점이 이동한다.
- 동전_수를 연결하면 완료 안내가 표시되고, 두 동전을 누르면 점수판이 2를 표시한다.
- 중지 후 잘못된 식을 입력하면 안내와 작성 내용이 유지되어 수정할 수 있다.
- 없는 변수를 연결하여 실행하면 —를 표시한다.
- 다시 동전_수에 연결한 뒤 새로고침·다시 시작하면 연결이 유지되고 0을 표시한다.

한글 조합 중 제출 방지는 기존 입력 제어기의 단위 테스트로 확인하였다. 운영체제 IME의 실제 조작, 작은 화면의 별도 검증, Python 3.10 및 별도 장비 실행은 수행하지 않았다. 기존 수업 HTML은 이번 디스플레이 구현에서 수정하지 않았다.

로그는 artifacts/display-*.log에, 설치본 동작 검사는 artifacts/verify-installed-displays.py에 있다.
