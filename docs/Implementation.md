# BlackPy 구현 구조

BlackPy는 프로젝트의 고정된 실행본과 그 실행에서 발생하는 입력·행동·장면·출력을 하나의 생명주기로 관리한다.

## 목차

- 전체 구조
- 구성 요소의 책임
- 설치와 편집기 연결
- 실행본과 코드 연결
- 이벤트와 동시 실행
- 시간과 움직임
- 입력과 접촉
- 상태·종료·실행 경계

## 전체 구조

로컬 실행부가 프로젝트 설정과 등록된 스크립트의 바이트를 읽어 별도 Python 프로세스에 전달한다. Python 실행기는 스크립트마다 객체를 만들고 상태와 동작을 연결한다. 웹 입력은 로컬 실행부를 거쳐 Python으로 전달되며, Python이 만든 장면은 검증 후 WebSocket으로 웹에 전달된다.

캐릭터 움직임·접촉·이벤트의 주체는 Python 실행기이다. 기존 고양이 전용 이동 경로는 사용하지 않는다. C# 실행부는 프로세스 수명과 전달 경계를 관리하며, 웹은 상태를 그리는 책임을 가진다.

## 설치와 편집기 연결

설치형 패키지는 Windows x64 실행부·웹·Python 지원 모듈·라이선스와 새 프로젝트 원본을 보유한다. 학생 파일은 패키지 설치 위치 밖의 프로젝트 폴더에 생성하며, 기존 파일이 있는 폴더에 새 프로젝트를 만들지 않는다. 패키지 제거와 재설치는 학생 폴더의 수명과 분리된다. 빌드는 별도의 새 배포 폴더와 기본 프로젝트 원본에서 패키지를 만들고 학생이 수정한 배포본을 입력으로 사용하지 않는다.

설치형 명령은 자기 Python 경로를 실행부에 전달하고 별도 콘솔 창 없이 실행부를 시작한다. 프로젝트의 절대경로를 명시하므로 명령을 호출한 작업 폴더나 패키지 설치 위치에 프로젝트 선택이 묶이지 않는다. 명령은 실행부의 종료를 기다리며, 마지막 브라우저 연결에 대한 수명 규칙은 폴더 배포본과 같다.

편집기용 타입 정의는 프로젝트에 암시적으로 제공하는 이름을 알려 주며 런타임에는 실행되지 않는다. 추가 작업은 학생 코드나 편집기 설정을 고치지 않으며, 기존 안내 파일의 내용이 다르면 교체를 거절한다. 이 정의는 일반 함수 호출과 상태 조회를 설명하는 수단이며, 코드 변환이나 이벤트 동시 실행을 편집기에서 재현하지 않는다. 배경의 움직임 금지 등 실행 대상의 제약은 런타임이 검사한다.

## 실행본과 코드 연결

프로젝트 설정은 배경과 캐릭터를 명시적으로 등록한다. 각 객체는 고유한 이름과 프로젝트 바로 아래의 서로 다른 Python 파일을 가진다. 파일 이름은 Windows의 대소문자 비구분을 고려하여 중복을 검사하며, 외부 경로와 연결 파일은 실행본에 포함하지 않는다.

시작할 때 설정을 한 번 읽고 등록된 파일 전체의 바이트를 고정한다. 모든 스크립트를 구문 분석한 뒤 초기 설정과 이벤트를 준비하고, 준비가 끝나면 시작 이벤트를 실행한다. 초기화 구간에는 상태·절대 설정과 출력을 허용하며, 갱신 루프를 기다리는 이동·회전·대기는 오류로 거절한다. 실행 중 저장한 코드·설정은 현재 실행에 섞이지 않는다. 추가로 import하는 모듈은 고정 범위 밖이다.

일반 def와 호출은 내부의 협력 실행 코드로 변환된다. 상태 이름의 읽기·대입은 해당 파일 객체의 속성과 연결되며, 별도 self나 global이 필요하지 않다. 원래 파일 경로와 줄 번호, 실행에 사용한 소스는 보존하여 오류에 사용한다. 학생 코드에 클래스·명시적 async/await·yield를 쓰는 방식은 지원하지 않는다.

## 이벤트와 동시 실행

일반 이벤트의 같은 호출이 진행 중이면 같은 재입력을 무시한다. 객체와 이벤트 종류를 기준으로 구분하고, 키 입력과 방송은 키 이름·신호 이름까지 구분한다. 다른 키나 다른 신호는 병행할 수 있다.

유지 이벤트는 키 유지·자신 클릭 유지·접촉 유지의 세 종류이다. 매 프레임 새 호출을 만들며 이전 호출이 끝나기를 기다리지 않는다. 종료 이벤트는 유지 이벤트가 아니므로 일반 이벤트 규칙을 적용한다. 상태가 해제되면 새 유지 호출만 멈추고 기존 호출은 완료한다.

한 호출의 명령은 완료 순서를 유지한다. 보조 함수를 호출하면 호출한 이벤트의 일반·유지 문맥을 이어받는다. 방송 수신은 별도의 일반 이벤트 문맥에서 실행되며 송신자는 수신 함수의 완료를 기다리지 않는다.

실행기 자체는 하나의 asyncio 루프에서 학생 실행을 조율한다. 함수 진입과 for·while 반복에는 실행을 양보하는 지점을 둔다. Python 외부 함수의 긴 동기 작업까지 비동기로 바꾸는 것은 아니다. 브라우저 제어와 프로세스 종료는 별도 실행부에서 처리한다.

동시에 활성화된 호출은 실행 전체에서 최대 4,096개이다. 초과하면 호출을 조용히 생략하지 않고 한국어 오류로 실행을 종료한다. 특히 유지 이벤트에 긴 대기나 끝나지 않는 반복을 넣으면 호출이 누적될 수 있다.

## 시간과 움직임

런타임은 초당 60회 갱신을 목표로 하며 실제 단조 시계의 경과 시간으로 이동을 계산한다. 웹의 화면 그리기 횟수와 런타임 갱신 횟수는 별개이다.

일반 상대 이동은 명령 시작 당시의 방향·속도 배율을 사용하여 목표 변화량을 시간에 나누어 적용한다. 기준 속도는 초당 200단위, 회전은 초당 180도이다. 유지 이벤트의 값은 초당 이동량 또는 회전 각도이며, 호출을 만든 프레임의 경과 시간과 현재 속도 배율을 곱해 즉시 적용한다.

같은 객체의 여러 상대 동작은 위치를 각각 덮어쓰지 않고 변화량을 더한다. 위치·방향의 절대 설정은 즉시 반영되며, 진행 중인 상대 동작의 남은 변화량은 이후에도 계속 더해진다. 따라서 절대 설정은 다른 호출의 이동을 취소하는 명령이 아니다.

## 입력과 접촉

키의 눌림·해제는 상태 전환으로 처리하고 브라우저의 자동 반복 입력은 별도 누름으로 처리하지 않는다. 유지 이벤트는 현재 누른 각 키에 대해 갱신 프레임마다 발생한다.

자신 클릭은 마우스 왼쪽 버튼을 누른 순간의 위치로 대상을 정한다. 가장 앞에 있는 보이는 캐릭터를 고르고, 없으면 배경을 선택한다. 포인터가 움직여도 버튼 해제까지 대상을 고정한다. 초점 상실·연결 변화는 누른 키와 버튼을 해제한다.

접촉은 모든 보이는 캐릭터의 사각 범위를 비교한다. 경계에 정확히 닿아도 접촉이다. 이전·현재 접촉 집합의 차이로 새 접촉·유지·종료 목록을 만들고, 같은 프레임의 접촉 목록은 학생 함수가 상태를 바꾸기 전에 고정한다. 이름 목록의 순서는 프로젝트 등록 순서이며 빈 목록은 호출하지 않는다.

## 상태·종료·실행 경계

각 실행은 새 식별자를 갖는다. 이전 실행의 입력·장면·조회 요청은 현재 실행에 적용하지 않는다. 실행 중 중복 시작은 거절하며, 재시작은 기존 프로세스와 자식을 정리한 뒤 새 실행본을 읽는다.

시작 이벤트만 있는 프로젝트는 모든 호출이 끝나면 완료된다. 다른 이벤트가 등록된 프로젝트는 입력을 기다린다. 처리되지 않은 오류는 실행 전체를 끝내며, 중지·완료 뒤 마지막 장면과 로그는 남는다. 마지막 웹 연결을 닫으면 학생 실행과 자식 프로세스를 중지하고 3초 뒤 로컬 실행부도 종료한다.

연결이 남아 있거나 유예 시간 안에 다시 연결되면 실행부 종료를 취소한다. 새로고침은 실행부와 마지막 장면을 유지하지만 학생 실행은 중지된 상태이다. 자동으로 브라우저를 여는 실행은 첫 연결을 최대 60초 기다린다. 직접 연결하는 `--no-browser` 실행은 첫 연결 제한 없이 기다리고, 한 번 연결된 뒤에는 같은 종료 규칙을 적용한다. 브라우저 열기 자체가 실패하면 실행부도 오류로 종료한다.

폴더 배포본의 기본 진입점은 콘솔을 할당하지 않는 Windows GUI 실행 파일이다. 관리 코드와 동봉 런타임은 공통 실행부 폴더에 두며, 진입점이 자기 위치 기준 상대경로로 불러온다. 프로젝트는 진입점과 같은 폴더에서 찾고 명시적인 `--project`가 있으면 그 경로를 우선한다. 학생에게 콘솔을 닫는 별도 종료 절차를 요구하지 않는다.

입력 대기열과 장면 데이터에는 상한이 있다. 연속 포인터 이동은 합치되 누름·해제 순서를 보존하며, 입력 초기화는 대기열이 찼을 때도 처리한다. 장면은 검증 후 복사된 상태로 보관한다.

서비스는 로컬 주소에서만 열고 API·WebSocket에 연결 토큰을 요구한다. Origin과 Host를 검사한다. 이는 실행 경계이며 Python 코드를 격리하는 보안 샌드박스는 아니다. 별도 사용자 코드의 파일·네트워크 접근은 일반 사용자 권한으로 실행된다.
