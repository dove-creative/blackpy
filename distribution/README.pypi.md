# BlackPy

BlackPy는 배경과 캐릭터마다 작성한 Python 코드를 로컬 웹 무대에서 실행하는 교육용 프로그램이다. 학생은 VS Code에서 일반 `def`와 한글 명령으로 코드를 작성하고, 웹의 명령 목록을 클릭해 필요한 코드를 복사한다. `class`, `self`, `async`, `await`나 BlackPy용 `import`를 직접 작성할 필요가 없다.

명령 팔레트는 모든 객체가 함께 사용하며, 실행 대상은 코드를 쓴 파일로 정한다. 배경에서 이동·회전·크기·물리 등 캐릭터 전용 함수를 호출하면 무시하고 다음 코드를 실행한다.

0.1.4의 `말하기("점수:", 3, 시간=1.5)`는 여러 값을 공백으로 이어 1.5초 동안 표시한다. 시간 없이 호출하면 계속 표시하며, `말하기()`로 지울 수 있다.

0.1.6부터는 프로젝트의 `_blackpy` 폴더에 png·jpg·gif·webp·svg 그림을 두고 `_blackpy/project.json`의 배경·캐릭터에 `"image": "우주센터.svg"`처럼 파일 이름을 적어 무대 그림으로 사용할 수 있다. 크기와 충돌 판정은 `kind`의 기본 모양을 따른다.

## 설치와 실행

Windows x64와 Python 3.10 이상, 웹 브라우저가 필요하다. 패키지에는 .NET·ASP.NET Core 런타임이 포함되어 있으며 BlackPy 외의 Python 실행 의존성은 없다.

```powershell
python -m pip install blackpy
blackpy new 내프로젝트
blackpy run 내프로젝트
```

이미 설치했다면 학생 코드를 실행할 Python 환경에서 다음 명령으로 갱신한다. 0.1.2는 이전 로컬 0.1.1 wheel과 버전을 구분한 공개본이며, 물리 명령이 없는 이전 설치본도 갱신할 수 있다. 학생 파일과 `project.json`은 유지된다.

```powershell
python -m pip install --upgrade blackpy
```

`new`는 없거나 비어 있는 폴더에 새 프로젝트를 만든다. 기존 학생 파일은 덮어쓰지 않는다. `blackpy` 명령을 찾지 못하면 `python -m blackpy new 내프로젝트`와 `python -m blackpy run 내프로젝트`를 사용한다.

0.1.1부터는 학생 프로젝트의 어느 `.py` 파일이든 실행하여 웹 무대를 열 수 있다. VS Code에서 BlackPy를 설치한 Python을 선택한 뒤 `고양이.py`나 `배경.py`의 'Run Python File'을 누르거나 다음 명령을 사용한다.

```powershell
python 내프로젝트/고양이.py
```

선택한 파일 하나가 아닌 프로젝트에 등록된 배경·캐릭터 전체를 준비한다. 등록하지 않은 `.py` 파일도 무대를 여는 진입점으로 사용할 수 있지만 캐릭터로 자동 추가되지는 않는다. 학생 파일에는 실행용 코드를 넣지 않는다.

```text
내프로젝트/
├─ 배경.py
├─ 고양이.py
├─ 자동차.py
└─ _blackpy/
   ├─ project.json
   └─ __builtins__.pyi
```

공통 실행부는 설치한 Python 환경에 들어가며 학생 파일은 프로젝트 폴더에 남는다. `run`은 웹 브라우저를 열고 실행부의 별도 콘솔 창은 만들지 않는다. 명령을 입력한 터미널은 실행부가 끝날 때까지 기다린다. BlackPy의 마지막 브라우저 탭이나 창을 닫으면 약 3초 뒤 실행부도 종료된다.

## 텍스트 입력

0.1.1부터 학생 스크립트의 `input()`은 실행기 콘솔에서 답을 받아 문자열로 반환한다. 콘솔의 출력 다음에 질문과 입력칸이 이어지며, Enter 또는 입력 보내기 버튼으로 제출한 질문과 답은 콘솔에 남는다. 파일 맨 위와 시작·일반 이벤트 안에서 사용할 수 있다.

```python
대답 = input("좋아하는 동물은?")
print(대답)
거리 = int(input("몇 칸 움직일까요?"))


def 시작():
    앞으로(거리)
```

여러 질문은 순서대로 표시하며 이벤트에서 답을 기다리는 동안 다른 이벤트는 계속 실행된다. 빈 답과 공백도 그대로 반환하고, 숫자가 필요하면 `int()` 또는 `float()`로 변환한다. 매 프레임 호출되는 유지 이벤트 안에서는 input을 사용할 수 없다. 중지·재시작하면 남은 질문을 취소한다.

## 첫 코드

VS Code에서 `내프로젝트` 폴더를 열고 `고양이.py`를 다음과 같이 작성한다. 웹의 시작 버튼을 누른 뒤 무대를 클릭하고 오른쪽 방향키를 누른다.

```python
def 시작():
    말하기("오른쪽 방향키를 누르고 있어 보세요!")


def 키_클릭_중(누른_키):
    if 누른_키 == "오른쪽":
        방향 = 0
        앞으로(120)
```

고양이는 오른쪽 키를 누르는 동안 초당 120만큼 움직인다. 일반 이벤트에서 `앞으로(120)`은 총 120만큼 이동하는 명령이고, `~중` 이벤트에서는 초당 이동량을 뜻한다. 속도 배율의 기본값은 1이다.

C# 실행부는 등록된 이동·물리·장면을 Python과 독립적으로 최대 60Hz로 갱신한다. 학생이 Python 루프를 60Hz에 맞추거나 프레임별 이동량을 계산할 필요는 없다. 키를 놓으면 실행부가 해당 유지 이동을 즉시 끝낸다.

Python 파일 실행은 웹 무대를 여는 동작이다. 한글 명령과 이벤트는 BlackPy 실행기가 연결하며 열린 무대의 시작·중지·다시 시작으로 제어한다. 코드 변경은 웹에서 다시 시작할 때 반영된다.

직접 실행은 사용 중인 Python에 BlackPy가 설치되어 있고 학생 파일 옆에 `_blackpy/project.json` 또는 기존 `project.json`이 있을 때 동작한다. 다른 Python 환경이나 BlackPy를 제거한 환경에서는 일반 Python 실행으로 돌아간다. 하위 폴더의 파일, 선택 코드 실행, 모듈·명령 문자열·대화형 실행과 `-S` 실행은 이 연결의 대상이 아니다. 설정 오류는 `blackpy run 내프로젝트`로 확인할 수 있다.

## VS Code 명령 안내

0.1.3의 pip 설치형은 VS Code의 Python·Pylance 확장에서 BlackPy를 설치한 Python을 선택하면 폴더 없이 학생 파일만 열어도 `말하기` 등의 명령과 인자를 안내한다. 학생 코드의 import나 VS Code 설정 변경은 필요하지 않다. 일반 이름·타입 오류는 계속 검사하므로 명령 이름의 오타도 확인할 수 있다.

환경 안내는 같은 Python을 사용하는 일반 Python 파일에도 적용되지만, 실제 한글 명령 실행은 BlackPy 프로젝트에서만 제공한다. 사용자 정의 안내 파일은 덮어쓰지 않으며 기존 정의를 우선한다. 프로젝트 폴더를 여는 기존 방식도 지원하며, 이전 프로젝트에는 다음 명령으로 안내 파일을 추가한다.

```powershell
blackpy editor 내프로젝트
```

학생 코드와 편집기 설정은 보존한다. 내용이 다른 안내 파일이 이미 있으면 덮어쓰지 않는다. 편집기 안내는 BlackPy의 코드 변환 전체를 검사하는 기능은 아니며, 함수 안의 `크기 += 0.1` 같은 상태 증감에는 일반 Python 분석기의 경고가 남을 수 있다. 크기 변경은 `크기_바꾸기(0.1)` 명령으로도 작성할 수 있다.

## 제공 범위와 라이선스

캐릭터별 움직임·말하기·크기·가시성, 키·클릭·접촉 이벤트와 방송을 제공한다. 0.1.1의 물리 기능은 객체별 없음·충돌만·물리 모드, 중력·충격·무대 사방 경계 충돌을 지원한다. 기본값은 충돌만이며 `물리_설정("물리")`, `무게_설정(1)`, `힘_작용(90, 6)`으로 물리 객체를 위쪽으로 한 번 밀 수 있다. `정지()`는 현재 속도만 지우고 중력은 계속 작용한다.

물리 계산은 동봉한 C# Box2D.NET이 담당하므로 별도 Python 물리 패키지를 설치하지 않는다. 접촉과 물리는 회전을 반영하지 않는 사각 범위를 사용하며 자동 회전과 소리는 제공하지 않는다. 학생 Python은 일반 사용자 권한으로 실행되며 보안 샌드박스로 격리되지 않는다.

MIT 라이선스이다. BlackPy와 Box2D.NET의 라이선스 및 제3자 고지는 설치 패키지에 포함되어 있다.
